# 黑白元素类（百大图形 19-26）

> 来源：H03 第 8-10 页、H04 第 1-8 页（讲义手写批注）+ L04 讲 PPT。
> 本章第一性原理：**轮廓规则 + 阴影元素不同 = 看「元素怎么摆」。** 黑白题先数「部分」，再看「排布」，最后才看「对称/笔画」。

## 一、识别信号

- 外轮廓是规则框架（宫格、蜂窝、圆、方格），内部由**黑/白两种色块**构成；
- 黑白元素的数量、形状、分布每图不同；
- 常见问法：一条式补「?」、分组分类（六个分两类）、九宫格；
- 选项往往是「同样是黑白块，只是分布不同」——规律大概率在**排布方式**。

## 二、综合导图（H04 P008 原文）

```
【飞哥传书】 黑白元素类 ——> 注重根据元素［排布］索引规律

图形导图·黑白元素
 ├ 顶格型 → 黑白分割 → 分割部分数/分割元素数
 ├ 离散型 → 黑白元素数量
 ├ 规则型 → 对称 → 对称方式/对称轴方向/轴过要素
 ├ 特殊型
 │  ├ 线连（单线/T型/Y型/十字型）→ 一笔画
 │  └ 点连 → 连接方式
 ├ 各行列分布型 → 元素传递/元素转换
 ├ 单片型
 │  ├ 规则 → 周长
 │  └ 不规则 → 面积
 ├ 线条型 → 要素位置/线过元素数
 └ 聚合型
    ├ 聚合度高 → 聚合元素位置
    └ 离散度高 → 白色区域数量
```

## 三、先判断三件事

1. **黑/白元素是「连成片」还是「散着」？**
   - 连成片且与轮廓边相接 → 顶格型（数分割部分）；
   - 散成多块 → 离散型（数元素数量）。
2. **黑白块的排布本身有没有规律？**
   - 有明显的行列/环形排布 → 规则型（看对称）；
   - 每行每列在变 → 各行列分布型（看传递/转换）。
3. **黑块是「一整片」还是「一条线」？**
   - 一整片 → 单片型（规则看周长，不规则看面积）；
   - 一条线 → 线条型（看线过格数/交点位置）。

**龙飞批注（H03 P009）**：
- 「1、元素数量是否一致；2、阴影数量多不多——数量多不好考移动。」

## 四、百大图形 19：黑白球顶格型

**特征**：黑球或白球**贴着外框边/顶到边界**，形成「分割线」，把另一色球切成若干部分。

### 4.1 黑/白顶格状 → 黑/白分割数量

- 案例 19.1.1 十六宫格（2021 北京）→ **B**。规律：白圆被黑圆分割的部分数依次 1→5。
  - 三行：共性识图·所有图形均由黑白元素构成 ｜ 细节定位·黑圆顶格 ｜ 选图思维·黑圆数量一致且黑白球离散度均递增·突出观感。
  - 批注：「白圆部分数量 1→5」「黑圆顶格状」。
- 案例 19.1.2 蜂窝状（2022 国考副省级、执法类）→ **D**。规律：白圆部分数 3、2、1 递减。
  - 三行：共性识图·所有图形均由黑白元素构成 ｜ 细节定位·黑圆顶格·贯穿 ｜ 选图思维·黑圆数量一致且黑白球离散度均递减·突出观感。

### 4.2 黑白均顶格状 → 分割数量和

- 案例 19.2.1（2024 福建/甘肃/广西/海南/河南/湖南/宁夏/云南）→ **C**。规律：黑部分数 + 白部分数 = 2、3、4、5、6，下一项 7。
  - 三行：共性识图·所有图形均由黑白元素构成 ｜ 细节定位·黑白圆均顶格 ｜ 选图思维·单独黑圆离散·规律排他。
  - 批注：上方标「黑」1、1、3、3、2，下方标「白」1、2、1、2、4；选项 C 下写「6+1」。

### 4.3 黑/白分割数量一致 → 元素数量分布

- 案例 19.3.1（2024 国考执法类）六个分类 → **A（①④⑥ / ②③⑤）**。规律：黑圆数量分布 2+4 或 1+5。
  - 三行：共性识图·所有图形均由黑白元素构成 ｜ 细节定位·白圆顶格 ｜ 选图思维·单独黑圆离散·规律排他；黑圆数量和部分均一致·突出观感。
- 案例 19.3.2（2025 四川）六个分类 → **B（①⑤⑥ / ②③④）**。规律：白圆数量分布 5+5 或 3+7。
  - 三行：共性识图·所有图形均由黑白元素构成 ｜ 细节定位·黑圆顶格 ｜ 选图思维·白圆数量和部分均一致·突出观感。

**易错**
- 顶格型不要数「总数」，要数「被分割成几部分」。
- 「部分数」与「数量分布」是两层：先看部分数是否一致，再看每部分里的元素数量。

## 五、百大图形 20：黑白离散型

**特征**：黑白球散落在框内，分割数 ≥4，没有明显顶格分割线。

**考法**：黑（白）圆的数量，按等差/交替变化。

- 案例 20.1.1（2022 国考地市级）→ **B**。规律：黑圆数量 9、10 交替。
  - 三行：共性识图·所有图形均由黑白元素构成 ｜ 细节定位·离散度高 ｜ 选图思维·离散度不单调·规律排他。
  - 批注：「黑圆 4 部分」。
- 案例 20.1.2（2023 北京）两组三图 → **D**。规律：两组黑圆数量分别 5、6、7 和 3、4、5。
  - 三行同上。批注：「黑圆 5 部分」。
- 案例 20.1.3（2025 浙江）→ **A**。规律：黑块数量 9→14（逐图 9、10、11、12、13，选项 A=14）。
  - 三行同上。批注：「黑块 5 部分」。
  - **答案冲突**：L03 P035 PPT 标「正确答案：B　三角形数量（0→5）」。按图逐格复核，黑块数量规则唯一指向 A（B=10、C=11、D=12），故正文取 A；B 的「三角形数量」无法从图面复核，暂记为 PPT 异说。

**易错**
- 离散度高时，**数量一定不单调递增**，常是交替或分组等差——不要硬套递增。
- 「散」不等于「乱」：先圈出黑球，再数，别被白球干扰。

## 六、百大图形 21：黑白规则型

**特征**：黑白元素在轮廓内**整行/整列、环形、对称**排布，排布本身很规整。

### 6.1 黑/白整行列排布 → 黑白对称

- 案例 21.1.1 对称方式（2021 国考副省级）→ **A**。规律：白圆对称方式轴对称/中心对称交替，黑白同时对称。
  - 三行：共性识图·所有图形均由黑白元素构成 ｜ 细节定位·黑圆整行列排布 ｜ 选图思维·各部分均规则·突出观感。
  - 批注：「白圆对称方式：轴对称和中心对称交替」「黑白同时对称」。
  - Tips：对称轴方向参见案例 3.2.1；轴过要素参见案例 3.2.3。L04 P005-P006 把这两个案例整页展开，形成「对称方式 → 轴方向 → 轴过要素」的递进：对称方式定不了答案时，依次往下看。
- 案例 21.1.2 环型轮廓（2021 国考地市级）→ **A**。规律：对称轴方向依次旋转 45°。
  - 三行：共性识图·所有图形均由黑白元素构成 ｜ 细节定位·环形轮廓 ｜ 选图思维·各部分均规则·突出观感。

### 6.2 对称轮廓 → 对称考法

- 案例 21.2.1 环型轮廓（2022 国考地市级、执法类）→ **A**。规律：对称轴方向依次旋转 45°。
  - 三行：共性识图·所有图形均由黑白元素构成 ｜ 细节定位·对称轮廓 ｜ 选图思维·各部分均规则·突出观感。
  - 蓝笔批注：「如果 D 改为上图，还是选 A，看轴过要素，题干对称轴只经过一个黑块。」
- 拓展演练（2025 国考副省级）→ **D**。规律：空白区域对称轴方向依次顺时针旋转 45°。
  - 三行：共性识图·所有图形均由空白和白块元素构成 ｜ 细节定位·白块整行列分布 ｜ 选图思维·白色区域均为单部分·突出观感。

**易错**
- 黑白规则型，「对称」优先看**白球/黑球各自**的对称，不要一上来就整体看。
- 轴过要素是「备用规律」：方向排不出唯一答案时，数轴经过几个黑块。

## 七、百大图形 22：黑白特殊型分布

**特征**：黑块连成**线状/特殊形状**（单线、T 型、Y 型、十字型），或黑块之间**点连接**。

### 7.1 黑白单线型/T 型/Y 型/十字型 → 一笔画

- 案例 22.1.1（2021 国考副省级、地市级）六个分类 → **C（①②⑥ / ③④⑤）**。规律：两笔画 / 一笔画。
  - 三行：共性识图·所有图形均由黑白元素构成 ｜ 细节定位·单线型和 Y 字型 ｜ 选图思维·黑圆单部分·突出观感。
  - 批注：「笔画数量：两笔画/一笔画」。

### 7.2 黑白点连接分布 → 连接方式

- 案例 22.2.1（2021 江苏 A、江苏 C）→ **C**。规律：黑圆数量 5 + 连接方式（点连接）。
  - 三行：共性识图·所有图形均由黑白元素构成 ｜ 细节定位·点连接。

**易错**
- 黑白块「连不连」很关键：连成线 → 数笔画；只靠点相接 → 看连接方式。
- 一笔画判定：连通图且奇点数为 0 或 2。
- **三个黑圆相接时，不考黑圆一笔画**（L04 P002 课程群答疑）：三圆相接的奇点结构排不出唯一答案，应转连接方式/数量。
- 叉字型与「又字型」是同一交叉形的两种写法，不要当成两个考点。

## 八、百大图形 23：黑白各行列分布

**特征**：黑白块按行/列排布，但每行每列的黑白在**逐图变化**。

**考法**：元素传递 / 元素转换。

- 案例 23.1.1（2025 国考地市级）→ **C**。规律：一二图首行黑白转换、二三图第二行黑白转换，依次递推。
  - 三行：共性识图·所有图形均由黑白元素构成 ｜ 细节定位·黑块各行列排布。
  - 批注：「黑白转换：一二图首行黑白转换；二三图第二行黑白转换……依次递推」。

**易错**
- 「转换」是一行一行往下推，不是全图同时翻转。
- 先锁定「哪一行在变」，再验证下一幅是否换到下一行。

## 九、百大图形 24：黑白单片型

**特征**：黑（或线围）区域是**完整一片**，面积较大且集中。

### 9.1 单片且规则 → 周长

- 案例 24.1.1（2022 四川下半年）六个分类 → **B（①②⑥ / ③④⑤）**。规律：黑色区域周长 10 / 12。
  - 三行：共性识图·所有图形均由黑白元素构成 ｜ 细节定位·单片且规则 ｜ 选图思维·正方形格子·便于命题。
  - 批注：「黑色区域周长 10/12」「凹→凸，可以等价为」。

### 9.2 单片且不规则 → 面积定量

- 案例 24.2.1（2024 四川）六个分类 → **D（①④⑤ / ②③⑥）**。规律：黑色区域面积 7.5 / 8.5。
  - 三行：共性识图·所有图形均由黑白元素构成 ｜ 细节定位·单片且不规则 ｜ 选图思维·正方形格子·便于命题。
  - 批注：「白：7+3×0.5=8.5」「2+4×0.5+2+3×0.5=7.5」。
- 案例 24.2.2（2022 安徽/黑龙江/湖北/吉林/江西/辽宁/内蒙古/山西/陕西/浙江 A、C）六个分类 → **C（①④⑤ / ②③⑥）**。规律：线围区域面积 7.5 / 10.5。
  - 批注：「5+3×0.5+4×0.5+0.5+2×0.5+0.5=10.5」。

**易错**
- 面积题先数「整格」，再数「半格（三角）」；半格统一按 0.5 计。
- 周长题遇到凹口，可「凹→凸」等价平移后再数边长。

## 十、百大图形 25：线条型

**特征**：轮廓内是**线条元素**（对号型、又字型、杂乱型），线条穿过网格。

### 10.1 对号型 → 端顶点位置 / 线过格子数量

- 案例 25.1.1（2024 广东）→ **C**。规律：线过格子数量为 8。
  - 三行：共性识图·所有图形均含线条型元素 ｜ 细节定位·对号型 ｜ 选图思维·九宫格对角线·便于命题。
  - 批注：「对号型还可以考端点的位置，即移动」。

### 10.2 叉字型（又字型）→ 十字交点位置 / 线过格子数量

- 案例 25.2.1（2024 甘肃/广西/海南/河南/湖南）→ **C**。规律：十字交点位置沿内环顺时针移动 1 格。
  - 三行：共性识图·所有图形均含线条型元素 ｜ 细节定位·叉字型。
  - 批注：「均为『叉』字型」（PPT 样式条印作「又字型」，指同一种交叉形）。

### 10.3 杂乱型 → 线过格子数量

- 案例 25.3.1（2025 天津）→ **A**。规律：线过格子数量 16。
  - 三行：共性识图·所有图形均含线条型元素 ｜ 细节定位·杂乱型。
  - 批注：「刀不能考十字」「杂乱型」。

**易错**
- 线条型优先数「线穿过几个格子」，不要急着数交点。
- 「又」字型有明确十字交点 → 交点位置可移动；杂乱型没有稳定交点 → 只能数线过格数。

## 十一、百大图形 26：聚合型

**特征**：大量**等腰直角三角形**聚合成图形，聚合程度不同。

### 11.1 聚合度高 → 聚合元素位置

- 案例 26.1.1（2025 国考副省级、执法类）六个分类 → **C（①③④ 中心 / ②⑤⑥ 角上）**。规律：大正方形聚合位置在中心/角上。
  - 三行：共性识图·所有图形均由黑白元素构成 ｜ 细节定位·等腰直角三角形聚合。
  - 批注：「大正方形聚合位置：中心/角上」。

### 11.2 离散度高 → 白色区域数量

- 案例 26.2.1（2026 国考副省级、地市级）→ **D**。规律：围成空白区域数量 0→5。
  - 三行：共性识图·所有图形均由黑白元素构成 ｜ 细节定位·离散度高 ｜ 选图思维·同向等腰直角三角形·便于命题。
  - 批注：「背景轮廓→题干图形带来最突出的视觉观感是相似」。

**易错**
- 聚合型不是数三角形个数，而是看「聚合体」在整体中的位置（中心/角上），或数被围出的空白区域。

## 十二、本章决策流

```
规则轮廓 + 黑白元素
├ 元素连片贴边 → 顶格型 → 数黑白各自被分割成几部分
│  ├ 部分数有规律 → 分割数量
│  ├ 黑白部分和 → 分割数量和
│  └ 部分数一致 → 数每部分元素数量分布
├ 元素散落（部分≥4）→ 离散型 → 数黑/白元素数量（交替、分组等差）
├ 排布整齐（整行列/环/对称）→ 规则型 → 对称方式/轴方向/轴过要素
├ 元素连成特殊形状 → 特殊型
│  ├ 线连（单线/T/Y/十字）→ 一笔画
│  └ 点连 → 连接方式
├ 每行每列在变 → 各行列分布型 → 元素传递/转换
├ 黑块一整片 → 单片型
│  ├ 规则 → 周长（凹→凸等价）
│  └ 不规则 → 面积（整格+半格×0.5）
├ 线条穿格 → 线条型 → 线过格子数 / 特殊交点位置
└ 三角聚合 → 聚合型
   ├ 聚合度高 → 聚合体位置（中心/角上）
   └ 离散度高 → 白色区域数量
```

## 十三、本章口诀

- **黑白题，先数块；连成片，看分割；散成沙，看数量。**
- **顶格数部分，离散数个数，整齐看对称。**
- **线连一笔画，点连看接法。**
- **单片规则数周长，不规则算面积（半格 0.5）。**
- **线穿格子数格数，又字交点看移动。**
- **三角聚合看位置，散开就数空白区。**
