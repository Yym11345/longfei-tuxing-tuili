# 修正图形类（百大图形 66-80）

> 来源：H09 第 9-13 页、H10 第 1-9 页（讲义手写批注）+ L10 讲 PPT。
> 本章第一性原理：**先认「基础图形」，再看它被「修正」成了什么。** 修正只有两条路：**加要素（数量）** 或 **改属性（笔画/对称/相同面/平行）**；对比修正则是「四个选项只有一个没被改坏」。

## 一、识别信号

- 图形都由一个**共同的基础图形**变来：相交圆、田字格、圆+叉、圆+Y、圆+N、圆+对号、圆+箭头、铜钱、锁芯、笑脸；
- 图与图之间「骨架相同」，只是加了线/点、或改了形状；
- 题型多为一条式；对比修正多为「以下哪项」式。
- 蓝笔首行统一写「特征识图」——先认基础图形，再定修正方式。

## 十八、本章决策流

```
认出基础图形（圆/田字格/圆+叉/Y/N/对号/箭头/铜钱/锁芯/笑脸）
├ 基础修正 → 看「修正了什么」
│  ├ 加了线/点 → 数交点、轮廓线数、面数、角数
│  ├ 改了形状 → 面为几边形、最小面与外轮廓相似
│  └ 改了属性 → 笔画、对称、相同面、平行、开闭
└ 对比修正 → 四个选项只有一个「没被改坏」
   ├ 形状修正 → 外轮廓 / 内部面形状
   ├ 数量修正 → 角、点、线
   ├ 位置修正 → 面数量（错位新增面）
   ├ 属性修正 → 对称/平行/开闭
   └ 方向修正 → 对称轴/对角线/平行线方向
```

## 十九、本章口诀

- **先认基础图，再看修正处。**
- **加线数交点，加框数面数，改形看边数，改性看笔画。**
- **铜钱看三不沾，锁芯看面数，笑脸看种类，对号看面形。**
- **对比修正找唯一：形状、数量、位置、属性、方向。**
- **选项有歧义，回题干找唯一属性。**
