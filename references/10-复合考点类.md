# 复合考点类（百大图形 56-65）

> 来源：H08 第 9-12 页、H09 第 1-8 页（讲义手写批注）+ L08 讲 PPT。
> 本章第一性原理：**单一规律不够用了——两个规律同时成立，且必须「先各自成立，再组合」。** 龙飞点明三个信号：单调特征、多图特征、特殊单图特征。

## 一、识别信号

- 图形规则/整齐，但**只用一个规律排不出唯一答案**；
- 图形呈现「复杂程度不单调」：轮廓线数忽多忽少，不是简单递增；
- 同一组图既有「移动/叠加/黑白转换」的痕迹，又有「数量/方向」的变化；
- 选项往往只能排除一两个，剩下的必须靠第二个规律。

## 二、综合导图（H09 P008 原文）

```
【飞哥传书】 复合考点类 ——> 重点关注单调特征、多图特征和特殊单图特征

综合导图（复合考点类）
├ 复杂程度不单调
│  ├ 多要素→多要素作差
│  └ 单要素→直角/一笔画
├ 不规则图形复合→轮廓线条数量
├ 规则图形复合
│  ├ 复杂程度不单调→对称轴与要素作差
│  ├ 复杂程度单调→对称与要素数量单独复合
│  ├ 规则+点连接→对称与一笔画单独复合
│  └ 规则+出头→对称与交点单独复合
├ 移动特征且复杂程度单调→移动与元素数量单独复合
├ 叠加特征且角度方向变化→同异叠加与旋/翻转复合
├ 黑白元素整体数量一致→元素转换与旋/翻转复合
├ 含十字型构成图形→横竖线数量关系
├ 含同/反向曲线构成图形→曲直数量关系
└ 含不规则曲线构成图形→轮廓线与交点关系
```

## 三、先判断「复杂程度」

1. **复杂程度单调** → 两个规律「并列」（对称 + 数量、移动 + 数量）。
2. **复杂程度不单调** → 两个要素「作差」（轮廓线 − 面数、轮廓线 − 最大面线数、轮廓线 − 内部点数）。
3. **多要素** → 多要素作差；**单要素** → 直角/一笔画。

## 四、百大图形 56：复杂程度不单调（多要素型）

### 4.1 轮廓线与内部面作差

- 案例 56.1.1（2021 江苏 A）→ **A**。规律：轮廓线数量 = 面数量（3、4、4、5、3）。
  - 三行：共性识图·复杂程度不单调 ｜ 细节定位·轮廓规则 ｜ 选图思维·图 2、图 4、B 选项、C 选项·便于命题；图 1、图 3、图 5·固有属性。
- 案例 56.1.2（2021 四川下半年）→ **C**。规律：轮廓线数量 = 面数量（3、4、3、6、5）。
  - 三行：共性识图·复杂程度不单调 ｜ 细节定位·轮廓规则 ｜ 选图思维·图 1、图 2、图 5·固有属性；图 3、A 选项·便于命题。

### 4.2 轮廓线与内部最大面线作差

- 案例 56.1.3（2022 天津）→ **C**。规律：轮廓线数量 = 最大面线数量（4、3、4、5、3）。
  - 三行：共性识图·复杂程度不单调 ｜ 细节定位·轮廓规则 ｜ 选图思维·图 2、图 4·固有属性；图 1、图 4·便于命题。

### 4.3 轮廓线与内部点作差

- 案例 56.1.4（2025 四川）→ **B**。规律：轮廓线数量 − 内部点数量 = 2（4-2、6-4、3-1、8-6、5-3）。
  - 三行：共性识图·复杂程度不单调 ｜ 细节定位·轮廓规则 ｜ 选图思维·AB 选项、CD 选项·便于命题。

**易错**
- 「作差」不是「相等」：先看两个数量是否相等，不等再算差。
- 轮廓线数要数「外轮廓的边」，不是所有线。

## 五、百大图形 57：复杂程度不单调（单要素型）

**考法**：直角 / 一笔画。

- 案例 57.1.1 直角（2021 安徽等六省）→ **B**。规律：直角数量 2→6。
  - 三行：共性识图·复杂程度不单调 ｜ 细节定位·轮廓均为正方形 ｜ 选图思维·图 2 直角修正·便于命题。
- 案例 57.1.2 一笔画（2022 福建等八省）→ **D**。规律：一笔画。
  - 三行：共性识图·复杂程度不单调 ｜ 细节定位·轮廓不规则 ｜ 选图思维·图 1 图 2 图 3·便于命题。

**易错**
- 单要素型只盯一个要素（直角或笔画），不要被轮廓变化带跑。

## 六、百大图形 58：不规则两种元素

**特征**：黑白两块不规则多边形组合（点连/分离）。

**考法**：线数量差。

- 案例 58.1.1（2022 福建等七省）→ **A**。规律：黑白多边形线条数量差 1、0、-1、1、0、-1。
  - 三行：共性识图·不规则两种元素 ｜ 细节定位·图形分离 ｜ 选图思维·凹多边形·突出观感。
- 案例 58.1.2（2024 国考执法类）→ **A**。规律：线条数量差 1/-1 交替（5-4=1，3-4=-1，4-3=1）。
  - 三行：共性识图·不规则两种元素 ｜ 细节定位·图形点连或分离 ｜ 选图思维·凹多边形·突出观感。
- 案例 58.1.3（2024 国考地市级）→ **B**。规律：两个多边形线条数量相等（6、4、5、3、5）。
  - 三行：共性识图·不规则两种元素 ｜ 细节定位·包含点连图形 ｜ 选图思维·凹多边形·突出观感。

**易错**
- 「不规则两种元素」先分别数线，再做差/相等；不要合并数总线条。

## 七、百大图形 59：规则图形复合型

### 7.1 规则且复杂程度不单调 → 对称轴与要素作差

- 案例 59.1.1（2022 广西）→ **A**。规律：对称轴数量 = 面数量。
  - 三行：共性识图·规则且复杂程度不单调 ｜ 细节定位·单区域等腰图形 ｜ 选图思维·日字型修正、田字格修正·便于命题。
  - 批注：「对称轴数量=面数量」「迎合数字」。

### 7.2 规则且复杂程度单调 → 对称与要素数量单独复合

- 案例 59.2.1（2023 浙江）→ **C**。规律：一条竖向对称轴，且面数量 2、3、4。
  - 三行：共性识图·规则且复杂程度单调 ｜ 细节定位·相似面、相同面。

### 7.3 规则且点连接 → 对称与一笔画单独复合

- 案例 59.3.1（2023 江苏 A）→ **B**。规律：对称轴方向旋转 45°，且均为一笔画。
  - 三行：共性识图·规则且点连接 ｜ 细节定位·圆形位置 ｜ 选图思维·相切圆·突出观感。

### 7.4 规则且出头 → 对称与交点单独复合

- 案例 59.4.1（2025 江苏 B）→ **D**。规律：对称轴横竖交替，且交点数量 2→7。
  - 三行：共性识图·规则且出头 ｜ 细节定位·又字型 ｜ 选图思维·图 3 图 4 修正·便于命题。

**易错**
- 规则复合先「把对称找出来」，再看「剩下的那个要素数量」。
- 「复杂程度单调」时两个规律并列；「不单调」时才作差。

## 八、百大图形 60：元素移动复合型

**特征**：图形在移动，同时元素数量也在变（单调递增/递减）。

- 案例 60.1.1（2021 广东）→ **C**。规律：内外环移动，且外环黑块前方 +1。
  - 三行：共性识图·移动样式且元素数量规律 ｜ 细节定位·黑块数量单调递增。
- 案例 60.1.2（2023 福建等八省）→ **D**。规律：顺时针旋转 2 格，且阴影前方 +1。
  - 三行：共性识图·移动样式且元素数量规律 ｜ 细节定位·阴影数量单调递增。
- 案例 60.1.3（2025 福建等八省）→ **D**。规律：黑白球内外环移动，黑球移动后方 +1、白球移动后方 +2。
  - 三行：共性识图·移动样式且元素数量规律 ｜ 细节定位·元素数量单调递增。
- 案例 60.1.4（2022 江苏 A、B）→ **D**。规律：中心元素 1、2 交替，三角形旋转，外环圆圈数量为 6。
  - 三行：共性识图·移动样式且元素数量规律 ｜ 细节定位·外环元素数量相等。
  - 批注：五图下方标「1+5」「2+4」「3+3」「2+4」「1+5」。

**易错**
- 移动复合：先锁定移动路径，再数「移动后方/前方新增的元素」。
- 「数量单调递增」是提示，不是答案——还要看新元素长在哪。

## 九、百大图形 61：同异叠加复合型

**特征**：九宫格/类比，前后图叠加，同时发生旋转或翻转。

- 案例 61.1.1（2021 江苏 B）九宫格 → **C**。规律：图 2 逆时针旋转 45° 后与图 1 去同存异。
  - 三行：共性识图·叠加样式且方向不一致 ｜ 细节定位·选项相似且方向不一致。
- 案例 61.1.2（2022 江苏 B）九宫格 → **A**。规律：同上。
- 案例 61.1.3（2024 四川）九宫格 → **B**。规律：图 1 图 2 去同存异，再顺时针旋转 90°。
- 案例 61.1.4（2025 国考副省级、执法类）九宫格 → **A**。规律：图 1 图 2 去同存异，再左右翻转。

**易错**
- 叠加复合的顺序很重要：先旋转/翻转再叠加，还是先叠加再旋转/翻转——用已知两图验证。
- 「去同存异」和「去异存同」只差一个字，看清题目呈现的是哪一个。

## 十、百大图形 62：黑白转换复合型

### 10.1 黑白元素数量呈规律 → 黑白转换

- 案例 62.1.1（2022 福建等七省）九宫格 → **C**。规律：每行图一图二黑白元素转换组合——图一黑圆数量 = 图三菱形数量，图二菱形数量 = 图三黑圆数量。
  - 三行：共性识图·黑白元素数量呈规律 ｜ 细节定位·选项数量相似且形状或黑白不同。

### 10.2 黑白转换且方向不一致 → 黑白转换与旋/翻转复合

- 案例 62.2.1（2022 四川）九宫格 → **A**。规律：图一图二左右翻转且黑白转换；图二图三黑白转换且线条虚实转换。
  - 三行：共性识图·黑白转换且方向不一致 ｜ 细节定位·选项相似且形状黑白不同。

**易错**
- 黑白转换要「按位置对」，不是按数量对。
- 方向不一致时，先判断翻转还是旋转，再套黑白转换。

## 十一、百大图形 63：包含十字型

**考法**：横竖线数量关系。

- 案例 63.1.1（2022 江苏 B、C）九宫格 → **A**。规律：每幅图横线数量比竖线数量多 1。
  - 三行：共性识图·图形包含十字型 ｜ 细节定位·分离图形纯横竖。
  - 批注：红笔标横线、蓝笔标竖线，逐个数线。

**易错**
- 十字型题只数横竖线，不数斜线；先分色标记再数，避免重复。

## 十二、百大图形 64：同/反向曲线型

**考法**：曲直数量关系。

- 案例 64.1.1（2023 北京）→ **A**。规律：直线与曲线数量差 2、1、0；1、0、-1。
  - 三行：共性识图·包含同/反向曲线 ｜ 细节定位·对称线条。
  - 批注：图上方标直线 4、2、2、6、3；图下方标曲线 2、3、2、5、3；A 下写「2-3=-1」。

**易错**
- 曲直数量关系先分别数，再做差；差值为 0 时也是规律。

## 十三、百大图形 65：不规则曲线型

**考法**：轮廓要素与内部交点作差。

- 案例 65.1.1（2023 河北/河南/江西）→ **B**。规律：轮廓线条数量 = 内部交点数量。
  - 三行：共性识图·包含不规则曲线 ｜ 细节定位·纯封闭图形、出头。
  - 批注：「破坏面的形状→不考面的数量」。

**易错**
- 不规则曲线会「破坏面」，所以不要数面；改数轮廓线与内部交点。

## 十四、本章决策流

```
单一规律不够用
├ 复杂程度不单调
│  ├ 多要素 → 多要素作差（轮廓线 vs 面/最大面线/内部点）
│  └ 单要素 → 直角 / 一笔画
├ 不规则图形复合 → 轮廓线条数量
├ 规则图形复合
│  ├ 复杂程度不单调 → 对称轴数量 vs 要素数量作差
│  ├ 复杂程度单调 → 对称 + 要素数量（并列）
│  ├ 点连接 → 对称 + 一笔画
│  └ 出头 → 对称 + 交点
├ 移动特征 + 复杂程度单调 → 移动 + 元素数量
├ 叠加特征 + 方向变化 → 同异叠加 + 旋转/翻转
├ 黑白元素总数一致 → 黑白转换 + 旋转/翻转
├ 含十字 → 横线数 vs 竖线数
├ 含同/反向曲线 → 直线数 vs 曲线数
└ 含不规则曲线 → 轮廓线数 vs 内部交点数
```

## 十五、本章口诀

- **一个规律排不完，两个规律一起看。**
- **复杂单调看并列，复杂不单调看作差。**
- **多要素作差，单要素看直角/笔画。**
- **对称配数量，移动配数量，叠加配旋转，黑白配翻转。**
- **十字数横竖，曲线数曲直，乱线数轮廓与交点。**
