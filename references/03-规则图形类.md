# 规则图形类（百大图形 1-3）

> 来源：H01 第 1-8 页（讲义手写批注）+ L01 第 1-? 讲 PPT。
> 本章第一性原理：**图形本身「规整」，命题人优先考「对称」。** 规则图形不考对称，才轮到面/数量等。

## 一、识别信号

看到下列特征，先归入本章：
- 图形轮廓规整：正多边形、圆、方框、等腰三角形、字母、箭头、星形；
- 图形有明显对称感（左右/上下/中心）；
- 题干反复出现同一种正多边形（正六边形、正五边形、正方形、正三角形）；
- 图形是「单面轮廓」或「外框+内部图形」的包含结构；
- 题干出现「字母元素」（M S D N A / T X Z K）——字母的固有属性就是对称。

## 三、对称「3+2」全解

龙飞把对称考点压缩成 **3 个基本量 + 2 个关系**：

| 考点 | 问什么 | 怎么判断 | 什么时候优先 |
|---|---|---|---|
| **对称方式** | 轴对称 / 中心对称 / 两者都有 | 沿某线对折重合＝轴对称；绕某点旋转 180° 重合＝中心对称 | 图形含字母、S/Z/N、纯中心对称图；题干出现「交替」 |
| **对称轴数量** | 有几条对称轴 | 逐条画：正 n 边形 = n 条；圆 = 无数条；长方形 = 2 条；正方形 = 4 条 | 非纯中心对称、正多边形、图形规整但方向不明显 |
| **对称轴方向** | 横 / 竖 / 斜（45°）/ 旋转 | 画出轴，比较相邻图的夹角 | 均单轴且有斜轴；九宫格每行方向一致 |
| **轴线关系** | 轴与图形线条：重合 / 垂直 / 平行 / 交替 | 看轴是否落在图形线条上 | 无斜轴、单轴图、内部有「悬空线条」 |
| **轴过要素** | 轴经过几个面/几个点/几条线/几个黑球 | 沿轴数经过的元素 | 无斜轴；轴经过相同面；黑白球对称 |

> 口诀：**先看方式，再数轴；有斜轴看方向，无斜轴看关系/过要素。**

## 四、整体形状规则（百大图形 1）

### 4.1 含中心对称图 → 对称方式 / 对称轴数量

**识别**：题干图形全部含中心对称（或纯中心对称）。

**分两支**：
- **纯中心对称**（没有对称轴）→ 只能考**对称方式**。
  - 龙飞原话：纯中心对称图「没有对称轴！！∴不能考对称轴数量、方向、轴线关系和轴过要素」。
- **非纯中心对称**（既有中心对称又有对称轴）→ 考**对称方式**或**对称轴数量**。
  - 龙飞原话：非纯中心对称图「不能考对称轴方向、轴线关系、轴过要素（必须只有一条对称轴）」。

**典型例题**
- 案例 1.1.1（2024 江苏 C）字母 M S D N A ? → **C（Z）**。规律：轴对称、中心对称交替。三行：共性识图·所有图形均规则 ｜ 细节定位·包含纯中心对称图形 ｜ 选图思维·字母元素·固有属性。
- 案例 1.1.2（2025 江苏 A）正多边形序列 → **B**。规律：对称轴数量 6→1。三行：共性识图·所有图形均规则 ｜ 细节定位·包含非纯中心对称图形 ｜ 选图思维·正六边形、正五边形、正方形、正三角形·固有属性。

**易错**
- 把「纯中心对称」当「轴对称」去数轴 → 0 条轴，数不出规律。
- 字母题先入为主按「笔画数/开口方向」做，忽略对称这一「固有属性」。

### 4.2 均单轴图 → 轴过要素 / 轴线关系 / 轴方向

**识别**：每个图形都只有一条对称轴（或都同为横竖轴）。

**分两支**：
- **无斜轴**（轴只有横/竖）→ 考**轴过要素**或**轴线关系**。
  - 轴过要素：轴经过的面数（如 3 个相同面 / 1 个面）、点数、线数。
  - 轴线关系：轴与图形线条重合 / 垂直 / 交替。
  - 龙飞批注：「无斜轴 → 不考对称轴方向」。
- **有斜轴**（出现 45° 斜轴）→ 考**对称轴方向**（常依次旋转 45°）。
  - 龙飞批注：「选项相似构成·便于命题」。

**典型例题**
- 案例 1.2.1（2023 国考副省级）六个图形分类 → **D（①⑤⑥ / ②③④）**。规律：轴经过面数量 3 / 1。三行：共性识图·所有图形均规则 ｜ 细节定位·均为单对称图形且无斜轴 ｜ 选图思维·相同元素构成·突出观感。
- 案例 1.2.2（2023 江苏 A）→ **D**。规律：对称轴与图形线条「重合/交替存在」。三行：…｜细节定位·均为单对称图形且无斜轴 ｜ 选图思维·悬空线条·突出观感。
- 案例 1.2.3（2025 浙江）→ **D**。规律：对称轴方向依次旋转 45°。三行：…｜细节定位·均为单对称图形且有斜轴 ｜ 选图思维·选项相似构成·便于命题。

**易错**
- 无斜轴却硬找方向，找不到就放弃；应转「轴过要素/轴线关系」。
- 有斜轴却去数面，忽略最显眼的方向变化。

### 4.3 均单面图 → 轴过轮廓要素

**识别**：图形是「一个封闭轮廓」，没有内部结构（单面）。

**考法**：对称轴经过轮廓的方式：
- **点入点出**：轴从轮廓的一个顶点进、另一个顶点出；
- **线入线出**：轴与轮廓的两条边相交（穿过边而非顶点）。

**典型例题**
- 案例 1.3.1（2022 国考副省级/地市级/执法类）六个单面轮廓分类 → **A（①②⑤ / ③④⑥）**。规律：点入点出 / 线入线出。三行：共性识图·所有图形均规则 ｜ 细节定位·均为单对称图形且单面图 ｜ 选图思维·单面图·突出观感 轮廓的观感。

**易错**
- 把「单面图」当「多面图」去数面；单面图没有内部面，只能看轴与轮廓的关系。
- 轴过顶点 vs 轴过边线，画图时要严格沿轴看「进出点」。

## 五、局部形状规则（百大图形 2）

> 基础前言：【局部规则】重点思考局部间规律关系，主要考察对称方式、轴方向。

### 5.1 包含分离结构（内外结构）→ 内外对称方式 / 轴方向

**识别**：外轮廓包住内部图形，内外**分离**（不接触）。

**考法**：
- 分别看外轮廓与内部图形各自的对称方式（轴对称/中心对称）；
- 或看内外对称轴的方向关系（垂直 / 平行 / 重合）。

**典型例题**
- 案例 2.1.1（2023 国考执法类）→ **D**。规律：外轮廓轴对称、内部图形中心对称。三行：共性识图·所有图形均外轮廓和内部图形规则 ｜ 细节定位·内外包含分离结构 ｜ 选图思维·五角星、Z 字型、等腰图形·固有属性。
- 案例 2.1.2（2022 江苏 A/C）→ **A**。规律：内外图形对称轴方向均垂直。三行：…｜细节定位·内外包含分离结构 ｜ 选图思维·等腰图形·固有属性；阴影图形·规律排他。

**易错**
- 只看外轮廓，忽略内部图形；或只看内部，忽略外轮廓。
- 内外轴关系有三种（垂直/平行/重合），不要只找「垂直」。

### 5.2 拼接结构 → 对称轴方向

**识别**：图形由两个规则面**沿公共边拼接**而成（白面拼接 / 黑白拼接）。

**考法**：两个拼接面各自的对称轴方向关系——**垂直 / 重合 / 45° / 平行**。

**典型例题**
- 案例 2.2.1（2021 浙江 A/B/C）白面拼接六个分类 → **B（①②⑤ / ③④⑥）**。规律：两拼接面对称轴方向「重合 / 垂直」。三行：共性识图·所有图形均由两个规则面构成 ｜ 细节定位·拼接结构 ｜ 选图思维·完全对接结构·便于命题。
- 案例 2.2.2（2022 广西/贵州/河南/湖南）黑白拼接 → **D**。规律：黑/白对称轴方向垂直 / 45° / 平行。三行：…｜细节定位·拼接结构 ｜ 选图思维·阴影图形·规律排他。

**易错**
- 把「拼接」当「包含」（两块是并列拼接，不是内外包含）。
- 只看整体对称轴，忽略两个组成部分各自的轴。

### 5.3 纯封闭结构 → 特殊面对称方式 / 轴方向

**识别**：外轮廓相同（或不同），内部被线条分成多个面，**无分离/拼接**。

**分三支**（看「特殊面」）：
- **外轮廓不同且规则** → 看**外轮廓**的对称轴方向；
- **外轮廓相同且最大面规则** → 看**最大面**的对称方式；
- **外轮廓相同且阴影规则** → 看**阴影面与规则白面**的对称轴方向关系。

**典型例题**
- 案例 2.3.1（2023 北京）→ **A**。规律：外轮廓对称轴方向依次旋转 45°。三行：共性识图·所有图形均由两个规则面构成 ｜ 细节定位·外轮廓不同且规则 ｜ 选图思维·内部均为 4 个面且不规则线条·突出观感。
- 案例 2.3.2（2024 福建/甘肃/广西/海南/河南/宁夏/云南）→ **C（①⑤⑥ / ②③④）**。规律：最大面中心对称 / 轴对称。三行：…｜细节定位·规则内部面为最大面 ｜ 选图思维·均为 5 个面且外轮廓相同·突出观感。
- 案例 2.3.3（2025 广西/河南/宁夏/云南）→ **A**。规律：阴影面与规则白面对称轴方向垂直 / 平行交替。三行：共性识图·所有图形均包含规则内部面 ｜ 细节定位·规则面为阴影面和 1 个白面 ｜ 选图思维·均为一黑三白且外轮廓相同·突出观感。

**易错**
- 外轮廓相同就只盯外轮廓，忽略内部「特殊面」。
- 「最大面」找错：先比较面积，不要凭感觉。
- 阴影题只看阴影，忽略白面的对称轴。

> Tips（原文）：局部规则对称考法均依赖「包含分离、拼接、纯封闭」等特殊结构关系。

## 六、位置排布规则（百大图形 3）

### 6.1 特殊规则轮廓 → 对称轴方向

**识别**：外轮廓特殊但规则（环形、拼接方格、蜂窝等），内部有阴影/黑白块排布。

**考法**：整体（或白球/黑球）的对称轴方向，常**依次旋转 45°**。

**典型例题**
- 案例 3.1.1（2021 国考地市级）环形规则轮廓 → **A**。规律：对称轴方向依次旋转 45°。三行：共性识图·所有图形均为环状规则轮廓 ｜ 细节定位·阴影排布规则 ｜ 选图思维·环状轮廓·固有属性；等腰排布·突出观感。
- 案例 3.1.2（2022 国考地市级/执法类）拼接规则轮廓 → **A**。规律：对称轴方向依次旋转 45°。三行：…｜细节定位·阴影排布规则 ｜ 选图思维·均有 3 黑 2 白·突出观感。

### 6.2 黑白球排布规则 → 对称方式 / 对称轴方向

**识别**：宫格内填黑白球，题干要求看「白球」或「黑球」的整体排布。

**考法**：
- 白球对称方式（轴对称 / 中心对称）；
- 白球/黑球对称轴方向（旋转 45°）；
- 黑球对称轴经过的黑球数量（轴过要素）。

**典型例题**
- 案例 3.2.1（2023 国考副省级/地市级）→ **A**。规律：白球对称轴依次旋转 45°。
- 案例 3.2.2（2024 四川）→ **C**。规律：白球均为中心对称。
- 案例 3.2.3（2025 国考地市级）六个分类 → **B（①②④ / ③⑤⑥）**。规律：黑球对称轴经过黑球数量 4 / 2。
- 拓展演练（2024 黑龙江）九宫格 → **C**。规律：每行图形对称轴方向一致。

**易错**
- 黑白球题一上来就数数量；先看「谁在对称」——题干要求白球还是黑球。
- 只看整体，忽略「轴过要素」（轴上经过几个黑球）。

## 七、本章决策流

```
图形规整/对称
├ 含中心对称图
│  ├ 纯中心对称 → 对称方式
│  └ 非纯中心对称 → 对称方式 / 对称轴数量
├ 均单轴图
│  ├ 无斜轴 → 轴过要素 / 轴线关系
│  └ 有斜轴 → 对称轴方向
├ 均单面图 → 轴过轮廓要素（点入点出/线入线出）
├ 局部结构
│  ├ 包含分离 → 内外对称方式 / 轴方向
│  ├ 拼接 → 两拼接面轴方向（垂直/重合/45°/平行）
│  └ 纯封闭 → 特殊面（最大面/最小面/外轮廓/阴影面）
└ 位置排布 → 轮廓/位置呈现 → 轴方向
```

## 八、本章口诀

- **规则先看对称，对称先看方式。**
- **纯中心没有轴，非纯中心可数轴。**
- **无斜轴看关系，有斜轴看方向。**
- **单面看轮廓，双面看拼接，内外看分离。**
- **局部特殊面：最大、最小、外轮廓、阴影面。**
