# 立体图形类（百大图形 81-100）

> 来源：H10 第 10-12 页、H11、H12（讲义手写批注）+ L10 第 30-44 页、L11 讲 PPT。百大 93-100 仅见 H12，无 PPT 双源。
> 本章第一性原理：**立体题不是「空间想象题」，是「把立体拆成平面要素」的判断。** 展开图看「面与面的相邻/相对」，视图看「投影轮廓与可见线」，切面看「截面轮廓与孔洞/阴影」，拼接看「逐层数量与特殊块」。

## 一、识别信号

- 题干出现立体图（立方体、四面体、八面体、组合体、积木堆）；
- 问法两类：
  - **展开图类**：「哪项可能是/不可能是其外表面展开图」「哪两个可以拼成」「求对立面」；
  - **视图类**：「哪项是/不是其视图」「三视图对应」「俯视图是」。
- 选项是展开图或视图，形状相近，差在面/线/阴影位置。

## 二、先分四类

1. **展开图类（81-88）**：把立体「摊平」，核心是**面与面的位置关系**。
2. **视图类（89-92）**：把立体「投影」，核心是**轮廓 + 内部可见线 + 阴影**。
3. **切面类（93-96）**：把立体「切一刀」，核心是**截面轮廓 + 空心/阴影的位置**。
4. **拼接类（97-100）**：把几个件「凑回去」，核心是**逐层数量 + 特殊块定位**。

## 三、百大图形 81：常规六面体型

**基础**：正方体六个面，相对面三组。页面例图骰子：上 5、下 6，中间 1 2 3 4；相对面 1-6、2-5、3-4。

### 3.1 无相同面型 → 点/线/面判断法

- 案例 81.1.1（2025 江苏 A）→ **A**。左边给定立方体，右边哪项可能是其外表面展开图。
- 方法：找「点/线/面」三类特征，逐项排除。

### 3.2 有相同面型 → 优先异面判断

- 案例 81.2.1（2024 四川）→ **C**。给定纸盒外表面，以下哪项能折叠而成。
- 批注：展开图内标红字编号 1-6；选项 A 打叉，C 打勾并标「6」「4」；D 右侧「应为点连接」。

**易错**
- 有相同面时，不要用「相同面」定位，先用**不同的那个面**（异面）定位。

## 四、百大图形 82：展开图求异型

**考法**：规范展开图比较——四个展开图中，哪一个折成的纸盒与其他三个不一样。

- 案例 82.1.1（2024 福建等七省）→ **B**。批注：「AB 不同」。
- 案例 82.1.2（2025 国考执法类）→ **D**（除哪项外都是同一正方体纸盒的展开图）。
- 方法：把每个展开图按「同一顶点/同一面」折叠，比较相邻关系。

**易错**
- 不要逐个折纸盒；先找「四个图中三个相同」的那个模式，再验证剩下的。

## 五、百大图形 83：四面体型

**考法**：规范展开图比较。

- 案例 83.1.1（2024 江苏 A、B、C）→ **D**。四个三角形展开图，找出还原后不一样的一个。
- 方法：四面体每个顶点周围有三个面；按「公共顶点」比较面序。

**易错**
- 四面体展开图没有「相对面」，只有「相邻面」，不能用六面体的相对面法。

## 六、百大图形 84：八面体型

**考法**：点/线/面判断法。

- 案例 84.1.1（2025 山东）→ **A**。给定多面体外表面展开图，哪个选项能折叠而成。
- 批注：「4 号面不可能和 2/2' 有公共边，BC 一定错」「23 面不选，因为有两个相同面」；选项 B、C 下「14 点连接」。

**易错**
- 八面体的「公共边」判断是核心：先标号，再排除不可能的公共边。

## 七、百大图形 85：异面体型

**考法**：对接边等长判断。

- 案例 85.1.1（2021 山东）→ **C**。给定立体图形，哪项是其外表面展开图。
- 案例 85.1.2（2022 山东）→ **B**。同上。
- 方法：异形立体的展开图，**对接边必须等长**；先量边，再看形状。

**易错**
- 异面体不要凭「看起来像」；对接边长度不等的一定错。

## 八、百大图形 86：积木阴影体型

**考法**：对接边阴影对称分布。

- 案例 86.1.1（2024 国考副省级）8 白 + 4 灰 → **D**。
- 案例 86.1.2（2024 国考地市级、执法类）8 白 + 4 灰，「不可能」型 → **D**。
- 案例 86.1.3（2025 国考副省级、地市级）4 黑 + 8 白 → **D**。
- 方法：灰/黑方块在对接边两侧应「对称分布」；先看阴影数量，再看相邻关系。

**易错**
- 「不可能」型问法：三个可能 + 一个不可能，找到违反阴影分布的那个。

## 九、百大图形 87：展开图拼合型

**考法**：先完整面、后残缺面判断。

- 案例 87.1.1（2025 河南）→ **B**（1 和 2 / 3 和 4 / 1 和 4 / 2 和 3 中选两块拼成同样展开图）。
- 案例 87.1.2（2025 天津）→ **C**。
- 方法：先找完整面确定方位，再用残缺面的缺口互补。

**易错**
- 拼合题不要先看残缺面；完整面是「定位锚」。

## 十、百大图形 88：组合体型

### 10.1 求展开图 → 先完整体、后隐藏体判断

- 案例 88.1.1（2025 福建等六省）→ **A**。两个正方体组合成长方体，其外表面展开图可能是。

### 10.2 求对立面 → 优先重复面递推判断

- 案例 88.2.1（2025 浙江）→ **B**。5 个相同纸盒依次摆放，问与面 1 相对的面。
- 方法：同一纸盒旋转后，重复出现的面可递推相对关系。

**易错**
- 组合体有「隐藏面」：被挡住的面不在展开图中，不要硬找。

## 十一、百大图形 89：常规视图型

**考法**：三视图——视角/轮廓/内部线判断法。

- 案例 89.1.1（2024 河北等五省）「不是」型 → **C**。
- 案例 89.1.2（2025 安徽等六省）三视图对应三个几何体 → **D（312）**。
- 方法：先看外轮廓，再看内部可见线（实线）和不可见线（虚线）。

**易错**
- 视图题先定「从哪个方向看」，再看轮廓；内部线只画「能看见的棱」。

## 十二、百大图形 90：积木视图型

**考法**：六视角判断（前/后/左/右/上/下）。

- 案例 90.1.1（2024 福建等六省）15 白 + 5 灰，「不可能」型 → **B**。
- 方法：灰块在某一视角可能被遮挡；逐视角检查灰块位置。

**易错**
- 「某个角度的视图」包括六个方向，不要只想到主视图。

## 十三、百大图形 91：视图推导型

**考法**：阴影位置判断。

- 案例 91.1.1（2025 甘肃/广西/海南）给左视图和主视图，求俯视图 → **A**。
- 方法：由两个视图反推三维阴影位置，再投影到俯视图。

**易错**
- 两个视图只能确定「有阴影的列/行」，要结合积木高度排除。

## 十四、百大图形 92：隐藏视图型

**考法**：黑白积木数量判断。

- 案例 92.1.1（2025 江苏 A、B、C）→ **D**。四个立体均由 8 白 + 4 灰堆成，找「某一视图可能纯白」的那个。批注：A「7W3B」若纯白只能是后视图，但剩一黑一白无法前后摆放，排除；D「7W3B」若纯白只能是俯视图，下黑上白能盖住；B、C「8W2B」还有两黑没看到，露出可能性大，排除。
- 案例 92.1.2（2025 浙江）→ **C**。墙角堆码 15 个纸箱，俯视图可能是。批注：可见 3+3+6=12；剩余 3 块若都在同一位置，说明三箱为一列、正视图可见，排除 A、D；再按缺口排除 B。
- 方法：隐藏视图 = 灰块被完全遮挡；先标每图白/黑块数（W/B），再判「从哪个视角、黑块能否全部被白块盖住」。
- 易错：「纯白视图」意味着灰块全部被白块挡住，不是灰块不存在；俯视图要结合「几块叠成一列」判断。

## 十五、百大图形 93：层级切面型

**考法**：给定立体，从任一面剖开，选「不可能」的截面。
**样式**：93.1 层级切面 → 基础/方向/等长/对称错误。

- 案例 93.1.1（2021 山东）→ **D**。两层长方体，上层斜切、下层前侧带斜面。批注：「切一刀」「切不出的图形是无限多的，关注错误选项」「对称等长」。
- 案例 93.1.2（2023 浙江）→ **D**。L 形台体中部带斜顶凸台。

**方法**：先看截面基础形状是否可能，再依次查方向、等长、对称。
**易错**：问「不可能」时不必证明三个可能，直接找违反「基础/方向/等长/对称」的那个。

## 十六、百大图形 94：镂空切面型

**样式**：94.1 镂空切面 → 展现/方向/数量错误。

- 案例 94.1.1（2023 国考副省级）→ **A**。大圆柱内挖空、上接小圆柱；A 同心圆环内圈画叉（该处不能是实心圆）。
- 案例 94.1.2（2022 浙江）→ **B**。三棱台内挖圆柱孔。批注：「图中有空心，一定在 AB 中选」；D「切一个角」。

**方法**：带空心时先锁定「截面是否展现空心」的候选，再查方向、数量。
**易错**：切面没穿过孔时截面就是实心；不能一律要求出现孔。

## 十七、百大图形 95：常规定点切面型

**样式**：95.1 常规定点切面 → 平行定位法。

- 案例 95.1.1（2025 甘肃/海南/河南/宁夏）→ **B**。沿 a、b、c 三点所在平面切开；批注「题目变简单」。
- 案例 95.1.2（2025 国考地市级/执法类）→ **A**。过 P、Q、R 三点切割。

**方法**：三点定面 → 用平行定位法把截面平移到选项，逐项比对轮廓与缺口。
**易错**：定点题不要凭空想象；三点给出后截面轮廓唯一，定位比推理快。

## 十八、百大图形 96：积木定点切面型

**样式**：96.1 积木顶点切面 → 先轮廓后阴影判断。

- 案例 96.1.1（2024 甘肃/广西/贵州/海南/河南/湖南）→ **C**。15 白 5 灰，过 A、B、C 三顶点；批注按 3/2/1 层数白格「3 1白／2 3白／1 2白」。
- 案例 96.1.2（2024 国考副省级/执法类）→ **B**。13 白 5 灰；批注「3 3白／2 2黑／1 白黑白」。

**方法**：先用三顶点定截面轮廓，再按层（3/2/1 层）核对阴影格。
**易错**：先数阴影会乱；轮廓定错则后面全错。

## 十九、百大图形 97：规则体拼接

**样式**：97.1 规则体型 → 逐层拼接。

- 案例 97.1.1（2025 广东）→ **C**。两件拼正方体；批注手绘三层 3×3 计数格，层 3 记「3差1」。
- 案例 97.1.2（2025 河北/湖北/湖南/江西/青海/陕西/重庆）→ **B**。3×3×3 正方体切去部分由 1、2、3 三块组成，选能填入问号的一块。

**方法**：逐层做 3×3 计数，算每层缺几块，再按缺块的形状选件。
**易错**：不要整体看外形；逐层数量差是硬约束。

## 二十、百大图形 98：异形体拼接

**样式**：98.1 异形体拼接 → 先特殊后一般。

- 案例 98.1.1（2024 山东）→ **A**。四个小多面体各用一次，选无法拼出的组合。批注：「数量都确定不了」。

**方法**：数量对不上或无从下手时，先拼最特殊、最不规则的那一块，其余自然归位。
**易错**：先从规则件入手会陷入枚举。

## 二十一、百大图形 99：标记体拼接

**样式**：99.1 标记体拼接 → 先阴影对应后定白块。

- 案例 99.1.1（2024 国考副省级/地市级）→ **A**。15 白 3 灰可由 1、2、3 三块组成；批注 P、Q 灰块「位置特殊，重点关注」。
- 案例 99.1.2（2025 福建/甘肃/贵州/河南/宁夏/云南）→ **D**。除哪项外三块可组合；批注 D「形状最复杂，最不规则」。

**方法**：先把标记阴影块对应到小件上，确定大件方位，再补白块。
**易错**：忽略灰块标记会失去唯一定位。

## 二十二、百大图形 100：相同体拼接

**样式**：100.1 相同体拼接 → 数量/对称判断。

- 案例 100.1.1（2025 国考执法类）→ **C**。3×3×4 空间内四个相同小多面体，选不可能拼成的；批注 C「不对称」。
- 案例 100.1.2（2024 广东）→ **D**。两个 8 块立体拼合；D「7 块，题干两个是 8 块，数量不对」。

**方法**：先数总块数，再判对称；数量不对或破坏对称的直接排除。
**易错**：相同体拼合优先数量与对称，不要先做形状枚举。

## 二十三、本章决策流

```
立体题
├ 展开图类
│  ├ 六面体
│  │  ├ 无相同面 → 点/线/面判断
│  │  └ 有相同面 → 优先异面判断
│  ├ 四面体 → 公共顶点面序
│  ├ 八面体 → 公共边标号排除
│  ├ 异面体 → 对接边等长
│  ├ 积木阴影 → 对接边阴影对称分布
│  ├ 拼合 → 先完整面、后残缺面
│  └ 组合体 → 先完整体、后隐藏体；求对立面用重复面递推
├ 视图类
│  ├ 常规三视图 → 视角/轮廓/内部线
│  ├ 积木六视角 → 逐视角查阴影
│  ├ 视图推导 → 两视图反推三维
│  └ 隐藏视图 → 灰块被遮挡，数层数/查遮盖
├ 切面类
│  ├ 层级切面 → 查基础/方向/等长/对称错误
│  ├ 镂空切面 → 先锁定空心展现，再查方向/数量
│  ├ 常规定点 → 三点定面，平行定位
│  └ 积木定点 → 先轮廓后阴影，按层数格
└ 拼接类
   ├ 规则体 → 逐层 3×3 计数
   ├ 异形体 → 先特殊后一般
   ├ 标记体 → 先阴影对应后定白块
   └ 相同体 → 数量/对称判断
```

## 二十四、本章口诀

- **展开图看相邻，视图看投影，切面看轮廓，拼接看数量。**
- **六面体找相对，四面体找公共顶点，八面体找公共边。**
- **异面体量边，积木看阴影，拼合先完整面。**
- **有相同面先找异面，组合体先找完整体。**
- **视图先轮廓后内线，隐藏视图数层数。**
- **切面「切一刀」，出错必在基础/方向/等长/对称；空心先看孔，定点用平移。**
- **拼接逐层数，特殊块先放；标记看阴影，相同看数量与对称。**
