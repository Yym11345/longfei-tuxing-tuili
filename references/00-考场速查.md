# 考场速查（一页版）

> 考前 10 分钟看这一页；做题卡住时回到这里选方向。

## 一、15 秒定性：这题属于哪一类

看**所有图形共同具备的局部特征**，说一句「所有图形均 ______」，再查表：

| 一句话特征 | 章节 | 第一反应 |
|---|---|---|
| 均规则（正多边形、对称） | 第一章 规则 | 对称方式→轴数→轴方向→轴线关系→轴过要素 |
| 均封闭（全是面） | 第二章 封闭 | 数面：不一致→形状/位置；=2→对接；=3→线连；≥4→特殊面 |
| 轮廓相同、格内有小元素 | 第三章 相同轮廓 | 平移→翻转→旋转→位置关系 |
| 有黑有白 | 第四章 黑白 | 分割部分数→数量→对称→笔画→连接→传递→面积周长 |
| 汉字/字母/logo/圆/标记 | 第五章 特殊元素 | 按载体查专属考点 |
| 两图长得像、可叠加 | 第六章 相似 | 黑白运算→去同存异→旋转翻转→种类数量→遍历 |
| 有局部特征图（纯曲直、平行、直角、分离、出头、中心） | 第七章 特征 | 按特征查表 |
| 一个规律排不完 / 数量忽大忽小 | 第八章 复合 | 作差：轮廓线=面、轮廓线±点、对称轴±面、两元素线数差 |
| 铜钱/田字格/圆+叉/Y/N/对号/笑脸 | 第九章 修正 | 先基础属性（笔画/面/对称）→再修正要素 |
| 立方体/展开图/三视图/积木/切面/拼接 | 第十章 立体 | 展开图→视图形状→切面轮廓→拼接数量 |

## 二、数什么：优先级

**面 → 线 → 点 → 素 → 角 → 笔画 → 部分**

- 面：封闭区域数（外轮廓也算 1 个面）。
- 线：直线数、曲线数、线条总数、平行线组数。
- 点：交点、曲直交点、切点、端点、出头点。
- 素：元素个数、元素种类、相同元素。
- 角：直角数（最常考）、锐角/钝角。
- 笔画：奇点 0 或 2 → 一笔画；奇点 2n → n 笔画。
- 部分：连在一起算 1 部分（点连/线连都算连通）。

## 三、对称「3+2」

| 先判 | 再选 |
|---|---|
| 纯中心对称（无轴） | 只能考**对称方式** |
| 非纯中心（有轴） | 可数**对称轴数量** |
| 单轴、无斜轴 | 考**轴线关系**或**轴过要素** |
| 单轴、有斜轴 | 考**对称轴方向**（常 45° 旋转） |

口诀：**先看方式，再数轴；有斜轴看方向，无斜轴看关系/过要素。**

## 四、一笔画判定

1. 数奇点（从这个点出发的线条数为奇数的点）。
2. 奇点 = 0 或 2 → 一笔画。
3. 奇点 = 2n → n 笔画。
4. 常见一笔画：日字型、圆内叉（一笔/两笔看交点）；田字格为两笔画。

## 五、命题人四种选项技术（选不出来时用）

| 技术 | 含义 | 怎么用 |
|---|---|---|
| 突出观感 | 把考点做得最显眼 | 选项里最「像」的那个常是陷阱，回题干找贯穿规律 |
| 规律排他 | 用另一条规律排除 | 两个选项都符合时，找能解释**全部**题干的 |
| 固有属性 | 图形天生带的属性（对称/笔画/面） | 先查固有属性，再看人为修饰 |
| 便于命题 | 图形被故意改成方便出题的样子 | 修正类题的核心：先还原基础图 |

## 六、验证四条硬标准

1. **贯穿性**：规律从第 1 图贯穿到最后 1 图。
2. **唯一性**：只有一个选项符合。
3. **简洁性**：能用一条规律解释，绝不叠两条。
4. **可复现性**：把规律说给别人，别人能选出同一答案。

## 七、时间与取舍

- 单题目标 40-60 秒；超过 90 秒先标记跳过。
- 图形推理整体控制在 8-10 分钟（10 题）。
- 分组分类题优先做（两条共性明确）；立体展开图放最后。
- 不会的题：先排除 2 个明显错的，再二选一，不空题。

## 八、最后 10 秒检查

- [ ] 规律能解释**所有**题干图？
- [ ] 分组题两组都成立？
- [ ] 有没有更简单的规律也能选同一项？
- [ ] 立体题相对面/公共边自洽？
- [ ] 答案字母与选项内容对应无误？
