# 训练与复盘

> 图形推理是「识别题型 → 调用规律」的条件反射，练的是**归类速度**，不是刷题数量。

## 一、三轮训练法

### 第一轮：分类练（按百大）
- 做法：一次只做同一百大的 5-10 题，做完立刻对答案。
- 目标：把「图形长相 → 百大编号 → 规律池」绑定。
- 通过标准：给出任意一题，10 秒内说出百大编号与第一考点。
- 建议顺序：1-8（规则/封闭）→ 9-18（轮廓）→ 19-26（黑白）→ 27-36（特殊）→ 37-41（相似）→ 42-55（特征）→ 56-65（复合）→ 66-80（修正）→ 81-100（立体）。

### 第二轮：混合练（打乱）
- 做法：把 20-30 题打乱，不标章节，限时 60 秒/题。
- 目标：练「没有提示时如何归类」。
- 通过标准：正确率 ≥ 80%，平均 ≤ 60 秒/题。
- 关键动作：每题做完先写一句「共性识图·______」，再对答案。

### 第三轮：限时套题
- 做法：10 题一组，8-10 分钟完成。
- 目标：练取舍与涂卡。
- 通过标准：正确率 ≥ 85%，且没有一题超过 90 秒。
- 关键动作：超过 90 秒先标记，做完再回看。

## 二、错题本字段（每题一行）

| 字段 | 填什么 |
|---|---|
| 题号/来源 | 年份+省份/模考 |
| 百大编号 | 我判的是哪个；正确答案属于哪个 |
| 共性识图 | 一句话「所有图形均 ______」 |
| 细节定位 | 唯一在变的细节 |
| 选图思维 | 命题人用的哪种选项技术 |
| 错因 | 见下方六类 |
| 正确规律 | 一句话，能复现 |
| 二刷结果 | 对/错/超时 |

## 三、错因六类（复盘必须先归类）

1. **归类错**：百大判错，规律池整个跑偏。
   - 对策：回到「共性识图」，重问「所有图形共同具备什么」。
2. **规律错**：类对了，但选的考点不对。
   - 对策：对照该章「先判断 N 件事」，按顺序排查。
3. **计数错**：数面/线/点/笔画时数错。
   - 对策：数两遍；先圈后数；用「总数−已数」校验。
4. **验证缺失**：规律只解释前几图，没贯穿。
   - 对策：把规律代回第 1 图与最后 1 图各验一次。
5. **选项误读**：看错选项图形或字母。
   - 对策：逐项写「错在…」；最后核对字母与内容。
6. **时间不足**：会做但没时间。
   - 对策：单题 90 秒强制跳过；先做分组/面数量题，立体放最后。

## 四、复盘五问（每题必答）

1. 这题的**共性识图**一句话是什么？
2. 我第一眼判的百大对不对？如果错，错在哪个特征没看到？
3. 唯一在变的细节是什么？有没有第二个也在变？
4. 命题人是用哪种选项技术设干扰的？
5. 下次遇到什么长相，我应该立刻想到这个考点？

## 五、每周统计表

| 指标 | 目标 | 本周 |
|---|---|---|
| 做题量 | 60-100 题 | |
| 分类正确率 | ≥ 90% | |
| 混合正确率 | ≥ 80% | |
| 平均用时 | ≤ 60 秒 | |
| 归类错占比 | ≤ 20% | |
| 二刷正确率 | ≥ 95% | |

> 归类错占比高 → 回去背 `00-考场速查` 与 `13-百大图形索引表`；
> 计数错占比高 → 专项练数面/数点/数笔画；
> 时间不够 → 练「90 秒强制跳过」。

## 六、二刷标准

- 错题隔 3 天做第二遍，隔 7 天做第三遍。
- 二刷必须**不看答案、不写三行**，直接选；选完再补三行。
- 连续两次二刷正确 → 移出错题本。
- 二刷仍错 → 回到对应章节正文，重读「识别信号 + 决策流」。

## 七、考场时间分配（图形推理 10 题）

| 阶段 | 时间 | 动作 |
|---|---|---|
| 第 1 遍 | 6-7 分钟 | 会做的直接选；卡住 60 秒标记跳过 |
| 第 2 遍 | 2 分钟 | 回看标记题，用排除法二选一 |
| 涂卡 | 1 分钟 | 核对字母与选项内容 |

## 八、每日 10 分钟微训练

1. 看 `00-考场速查` 的定性表 1 分钟（背「特征→章节」）。
2. 随机抽 3 道错题，只看图说「百大编号 + 第一考点」2 分钟。
3. 做 2 道新题，写三行 5 分钟。
4. 口述今天学到的一个「易错点」2 分钟。
