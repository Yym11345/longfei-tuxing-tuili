# 解题总流程：七步法

> 适用：所有图形推理题。龙飞课堂的讲解顺序是「先答案、再共性识图/细节定位/选图思维」；本卷把它还原成**做题时的正向流程**，并在最后给出与龙飞三行的对应关系。

## 第 0 步：审题（5 秒）

先看清三件事，避免方向性错误：

1. **题型**
   - 一条式：一串图形 → 问号
   - 两段式：前三个/前五个 → 后三个/后五个（通常规律相同或对应）
   - 九宫格：3×3（也有 4×4），按行/列/对角看
   - 分组分类：六个图形分两类（①②③/④⑤⑥），找两组的**各自共性**或**对比差异**
   - 立体：展开图/折叠、三视图、截面、立体拼合
2. **问法**
   - 「最合适的一个」→ 选使规律最完整、最简单的
   - 「分类正确」→ 两组必须各自成立，不能用「一组有规律、另一组没有」凑
   - 「去掉哪一个」→ 先找共性，再看谁破坏了共性
   - 「不可能是」→ 反向排除，找与规律冲突的
3. **题干来源**（若标注年份/省份）：仅作辅助，不要先入为主套某年考法。

## 第 1 步：共性识图（10 秒）

**只看「所有图形共同具备什么」，不看差异。**

依次扫八个问题：
- 图形是否**规则**（对称、正多边形、规整轮廓）？
- 图形是否**封闭**（全是面）？
- 轮廓是否**相同/相似**（元素在同一个框架里动）？
- 是否有**黑白/阴影**元素？
- 是否有**特殊载体**（文字、字母、logo、圆、开放线、标记）？
- 图形是否**两两相似**（形状接近，元素有增删）？
- 图形是否**复杂/生活化/多元素**（不想数数）？
- 是否**立体**（立方体、展开图、三视图、截面）？

> 输出一句话：**「所有图形均 ______」**。这句话就是龙飞的三行第一行。

## 第 2 步：定规律池（5 秒）

根据第 1 步的结果，跳到对应分卷，取该类的**优先规律池**（每类只取前 2-4 条，不要全试）：

| 共性识图结论 | 去哪卷 | 优先规律池 |
|---|---|---|
| 所有图形均规则 | 03-规则图形类 | 对称方式 → 对称轴数量 → 轴方向 → 轴线关系 → 轴过要素 |
| 所有图形均封闭 | 04-封闭图形类 | 面数量 → 面形状 → 面位置（含黑白面） |
| 轮廓相同、元素基本相同 | 05-相同轮廓类 | 平移（行/列/环路/斜向）→ 翻转 → 旋转 → 位置关系 |
| 含黑白元素 | 06-黑白元素类 | 分割部分数/元素数 → 黑白数量 → 对称 → 一笔画 → 连接方式 → 传递/转换 → 面积周长 → 位置 |
| 含特殊元素 | 07-特殊元素类 | 按载体查表（文字/字母/logo/立体平面/开放线/圆/标记） |
| 图形相似 | 08-相似图形类 | 黑白运算 → 同异叠加 → 旋转/翻转 → 元素种类/数量 → 遍历 |
| 有局部特征图（纯曲直/平行/直角/分离/复杂出头/中心特征） | 09-特征图形类 | 按特征查表 → 曲直定性 → 一笔画 → 直角 → 平行线 → 元素种类 |
| 单一规律明显但**数量不单调**（忽大忽小） | 10-复合考点类 | 轮廓线=面数量 → 轮廓线±内部要素 → 对称轴±要素 → 两种元素线数差 |
| 图形是**基础图的变体**（铜钱/田字格/圆+叉/圆+Y/圆+N/圆+对号/笑脸） | 11-修正图形类 | 先按基础图固有属性（笔画/面/对称）→ 再看修正要素（数量/形状/位置/属性/方向） |
| 立体 | 12-立体图形类 | 展开图（六面体/四面体/八面体/异面体）→ 视图（三视图/积木/推导/隐藏）→ 切面（层级/镂空/定点）→ 拼接（规则/异形/标记/相同） |

## 第 3 步：细节定位（20 秒）

**在规律池里，找「唯一在变」的细节。** 具体动作：

1. **数**：点、线、面、素、角、笔画数、部分数；先数最容易数的（面→线→点→素）。
2. **看方向**：对称轴方向、元素移动方向、旋转角度。
3. **看位置**：内外、左右、上下、相邻/相对、重合/分离。
4. **看形状**：相同面、相似面、最大面/最小面、特殊面。
5. **看关系**：相交/相切/包含、连接方式（点连/线连）、公共边。
6. **看运算**：前两图 → 第三图（叠加/去同存异/黑白运算）；数量之间的和差倍比。

> 输出一句话：**「细节在变的是 ______」**。这就是龙飞三行的第二行。

## 第 4 步：验证规律（30 秒）

按题型验证：

- **一条式**：规律必须从第 1 个贯穿到最后一个；常见节奏：等差、周期、交替、递推、两两分组。
- **两段式**：第一段的规律必须能原样套到第二段；也可能是「第一段 + 第二段 = 第三段」的对应关系。
- **九宫格**：优先按行看，其次按列看，最后看对角/整体；常见：每行数量相同、每行遍历、每行前两图运算得第三图。
- **分组分类**：两组各自满足一个共性，或两组在某一属性上互补（如一组轴对称、一组中心对称）。
- **立体**：展开图用「相对面不相邻、公共边等长、公共点唯一」；三视图用「可见/遮挡」；截面用「基础形状 + 方向 + 等长/对称」。

**验证不通过就换规律，不要改图形去迁就规律。**

## 第 5 步：选项排他（20 秒）

1. 先用规律**正向预测**问号处应具备的特征；
2. 再逐个选项对照，**先排除明显违反的**；
3. 剩下 2 个时，比较：
   - 哪个能让规律**贯穿全部题干**？
   - 哪个是命题人「故意做得像」的同构项？
   - 有没有更简单的规律能解释另一个选项？
4. 警惕「局部符合」：某选项只符合前三个图，不符合后两个，必错。

> 输出一句话：**「选项 ______ 使 ______ 贯穿，故选 ______」**。这就是龙飞三行的第三行。

## 第 6 步：复核（10 秒）

- 答案是否解释了**所有**图形？
- 是否存在**更简单**的规律也能选同一个答案？（若有，取更简单的）
- 是否存在**反例**？（尤其分组题，两组是否都成立）
- 立体题：相对面/公共边是否自洽？

## 第 7 步：卡住时的应急顺序

```
对称 → 面 → 移动 → 数量（点线面素角） → 曲直/开闭 → 一笔画 → 叠加/运算 → 位置关系 → 立体
```

但不要机械按顺序全试。正确做法：
- 回到第 1 步，重新问「我是不是归错类了？」
- 找「最反常的那个图形」：它往往暴露考点（如一串规则图中突然出现一个不规则图，可能考「突出观感」）。
- 找「选项之间的差异」：选项在哪些属性上不同，规律就可能在哪个属性上。
- 两条规律都成立时，选**能解释更多图形、规则更简单**的那条。

## 与龙飞三行的对应

| 七步法 | 龙飞三行 | 作用 |
|---|---|---|
| 第 1 步 共性识图 | 共性识图 | 定大类 |
| 第 2-3 步 定池 + 细节 | 细节定位 | 定规律 |
| 第 5 步 选项排他 | 选图思维 | 定答案 |
| 第 4/6 步 验证/复核 | （课堂上的「为什么不是别的」） | 防错 |

## 标准输出模板（精解时使用）

```
【题型】一条式 / 两段式 / 九宫格 / 分组分类 / 立体
【共性识图】所有图形均 ______
【细节定位】在 ______ 上，______ 成规律（具体：…）
【规律】______（用一句话说清，能复现）
【选项排他】A 错在…；B 错在…；C 错在…；D 符合…
【答案】__
【龙飞三行】共性识图·… ｜ 细节定位·… ｜ 选图思维·…
【一句话经验】______
```
