# 易错陷阱（按章节）

> 用法：错题复盘时先在这里找对应条目；每条都是「错误动作 → 正确动作」。

## 一、跨章节通用

1. **数面把外框也算一个面** → 只数封闭的空白区域；外轮廓本身不算面。
2. **规律只解释前三个图** → 必须从第 1 图贯穿到最后 1 图；局部符合即错。
3. **分组题两组只验一组** → 两组必须各自成立；「一组有规律、另一组没有」是凑答案。
4. **复杂图形不敢数** → 生活化图形也是面，照数；越复杂越要简化成面/线/点/素。
5. **先入为主套年份考法** → 题干来源只作辅助，先看图形本身。
6. **两条规律都能选同一答案时选复杂的** → 取更简单、能解释更多图形的那条。
7. **「最合适」当成「唯一正确」** → 选使规律最完整、最简单的一项，允许其他项局部相似。
8. **不检查选项字母与内容** → 涂卡前再对一遍。

## 二、对称类（第一、九章）

- 把「纯中心对称」当轴对称去数轴 → 纯中心对称没有对称轴，只能考对称方式。
- 无斜轴却硬找方向 → 转「轴过要素 / 轴线关系」。
- 有斜轴却去数面 → 方向变化最显眼，先看方向。
- 只看外轮廓忽略内部 → 内外两层题要分别看内、外，再看两者关系。
- 内外轴关系只找垂直 → 还有平行、重合。
- 把「拼接」当「包含」 → 两块并列拼接不是内外包含。
- 外轮廓相同就只盯外轮廓 → 看内部「最大面/特殊面」。
- 「最大面」凭感觉 → 先比较面积再定。
- 轴过顶点 vs 轴过边线混淆 → 严格沿轴看「进点/出点」。
- 铜钱型只数对称轴 → 固有属性还有「三不沾面、笔画、内外交点相同」。

## 三、面与封闭类（第二、四章）

- 面数不单调就放弃 → 转一笔画或复合考法（轮廓线=面、作差）。
- 把「对接边」当图形边 → 只数两个面共用的那条边。
- 两个面大小相近忽略长短边 → 对接边长短也是考点。
- 只数三角形漏掉其他形状 → 先分形状再数。
- 「相同面」与「相似面」混淆 → 相同 = 形状+大小都同；相似 = 只要形状同。
- 点连与线连混淆 → 共边是线连，只共一个点是点连。
- 多面题不先数面 → 先数面，面数相同再看点连方式。
- 黑白面直接看位置 → 先数黑白面数量，数量不通再看位置。
- 「白≥4」「白<4」两条分支混用 → 先数白面个数再选分支。

## 四、移动与轮廓类（第三、五章）

- 饱和时还找空格移动 → 看元素之间的位置关系（相邻/相对/相同）。
- 分组题套移动 → 分组考同图内元素关系或两组各自共性。
- 翻转与旋转混淆 → 翻转改变手性（左右互换），旋转不改变；看字母/箭头最快。
- 环路型+饱和当整体旋转 → 可能逐行/逐列旋转并传递。
- 线型元素走到端点当消失 → 是「传送」到另一端。
- 蜂窝型不看中心 → 中心一致走内外环，中心不一致走斜向。
- 分离型当整体移动 → 分别追踪每一部分。
- 只看整体方向忽略拐点 → 拐点常是特殊点。
- 跳棋盘按行列平移 → 按六边形相邻/隔线/隔位算。
- 十六宫格「少的分别移、多的整体移」用反 → 先数每格元素个数再定策略。

## 五、黑白元素类（第四、六章）

- 顶格型数总数 → 数被分割成几部分。
- 部分数与数量分布混为一层 → 先看部分数是否一致，再看每部分数量。
- 离散度高硬套递增 → 常是交替或分组等差。
- 黑白规则型一上来整体看对称 → 先看白球/黑球各自的对称。
- 有方向却先数轴过要素 → 方向能排答案时不必数。
- 黑白块连通性不看 → 连成线数笔画；只点接看点连接方式。
- 一笔画判定忘前提 → 必须连通且奇点为 0 或 2。
- 三个黑圆相接还硬考一笔画 → 三圆相接不考黑圆一笔画（L04 答疑），转连接方式/数量。
- 「叉字型」与「又字型」当两个考点 → 是同一种交叉形，别被印刷写法误导。
- 转换题全图同时翻 → 是一行一行往下推。
- 先锁定「哪一行在变」，再验证下一幅是否换行。
- 面积题漏半格 → 整格+半格（三角按 0.5）。
- 周长题遇凹口硬数 → 「凹→凸」等价平移后再数。

## 六、特殊元素类（第五章）

- 汉字先看笔画 → 纯横竖先数横竖线；有封闭先数面。
- 定性压过定量 → 龙飞明确「定量优于定性」；能数数先数数。
- 字母不列属性表 → 曲直、封闭、对称、部分数逐项套。
- 字母大小写混排按手写体 → 统一按印刷体看。
- logo 看「像什么」 → 只看几何属性：部分数、面数、对称。
- 立体图把切割线当面 → 数外表面。
- 立体+平面混排不降维 → 全立体数面；立体+平面数线/点。
- 回旋折线不先看直角/平行 → 先看视觉观感，再看首尾点。
- 交叉线不先数线段 → 线段数一致才看交点位置。
- 相切圆顺序乱 → 先数圆，再数切点，最后看切点属于哪个圆。
- 外接圆把割线当切线 → 擦边而过是切线，穿圆而过是割线。
- 贯穿圆数到圆外 → 只数圆内面。

## 七、相似与叠加类（第六、八章）

- 黑白运算不定规则就套 → 先用第一组前两图逐格验证。
- 出现缺口/空白漏第三种颜色 → 空也参与运算。
- 去同存异/去异存同/直接叠加混淆 → 先用第一组验证是哪一种。
- 九宫格不先判行列 → 看哪一方向能贯通三行/三列。
- 生活化图形试图理解画面 → 简化成元素种类、直线数、旋转。
- 旋转/翻转看错手性 → 翻转左右互换，旋转不换。
- 基础构成相同还数数量 → 数量都一样，看排布与位置关系。
- 位置构成相似不分内外 → 先分内/外、上/下，再比两层数量。
- 遍历题不查缺 → 每行/列元素种类齐全，缺什么补什么。

## 八、特征图形类（第七章）

- 中间单面当首尾递推 → 中间单面提示「全体共有的数量」。
- 内外都复杂先数面 → 先数笔画；笔画一致再看轮廓线 vs 内部交点。
- 平行线数条数 → 只数组数；N/Z 字型是 1 组平行。
- 直角只数轮廓角 → 内部线交角也算；田字格 8 个直角。
- 曲线不规则硬数曲线 → 只能考曲直定性。
- 三列曲直不先分列 → 先分纯直/纯曲/结合，再看第三列。
- 分离型笔画直接数整体 → 各连通部分笔画数相加。
- 九宫格中心题不看中心 → 先看中心格是否特殊，再看对角/四周。
- 复杂分离图先数个数 → 先看种类，再数个数。
- 纯曲直题把「类圆曲线」当普通曲线 → 类圆曲线是提示特征。
- 首位开放图去数线 → 先数面（0→5 是常见节奏）。
- 首位单面图去数面 → 单面图没有面可数，转曲直/笔画。

## 九、复合考点类（第八章）

- 「作差」当「相等」 → 先看两者是否相等，不等再算差。
- 轮廓线数成所有线 → 只数外轮廓的边。
- 单要素型被轮廓变化带跑 → 只盯直角或笔画。
- 不规则两元素合并数总线条 → 分别数再作差/比相等。
- 复杂程度单调与不单调混用 → 单调是两规律并列；不单调才作差。
- 移动复合只看路径 → 还要看移动后新增元素的数量/位置。
- 数量递增就当答案 → 递增只是提示，还要看新元素长在哪。
- 叠加与旋转顺序搞反 → 用已知两图验证先后。
- 「去同存异」「去异存同」看错一个字 → 对照图形逐格确认。
- 黑白转换按数量对 → 必须按位置对。
- 方向不一致不先判翻转/旋转 → 先判手性再套转换。

## 十、修正图形类（第九章）

- 相交圆只数圆内交点 → 圆与圆、圆与轮廓的交点都算。
- 田字格把十字交点当曲直交点 → 只数直线与曲线交点。
- 圆+叉修正常把圆换多边形后找不到骨架 → 先认基础骨架。
- 「面为几边形」看所有面 → 看最大面/特殊面的边数。
- 「轮廓线数=面数」不先验证 → 修正类常客，先数再比。
- 对号型顺序乱 → 面数量→面形状→笔画。
- 九宫格笔画按列看 → 是按行同笔画，不是逐图递增。
- 铜钱型忽略「三不沾面」 → 一个面同时不碰内圆、外圆、斜线。
- 锁芯型不先数面 → 先面数量，再用对称/平行排选项。
- 笑脸型被表情含义干扰 → 只看内部元素的曲直/种类。
- 形状修正只看内部 → 先外轮廓，再看内部最小/最大面是否同形。
- 数量修正三选一犹豫 → 看点/线/角哪个在单调变化。

## 十一、立体图形类（第十章）

- 有相同面还拿相同面定位 → 先用「异面」定位。
- 逐个折纸盒 → 先找四个图中三个相同的模式，再验证剩下。
- 四面体套六面体相对面法 → 四面体没有相对面，只有相邻面。
- 八面体不标公共边 → 公共边判断是核心，先标号再排除。
- 异面体凭「看起来像」 → 对接边不等长一定错。
- 「不可能」型按「可能」做 → 三个可能+一个不可能，找违反阴影分布的那个。
- 拼合题先看残缺面 → 完整面是定位锚。
- 组合体硬找被挡住的面 → 隐藏面不在展开图中。
- 视图题不先定方向 → 先定从哪个方向看，再看轮廓。
- 「某个角度的视图」只想主视图 → 六方向都要考虑。
- 两个视图直接定阴影 → 只能定「有阴影的列/行」，需结合高度。
- 「纯白视图」当灰块不存在 → 是灰块全部被白块挡住。
