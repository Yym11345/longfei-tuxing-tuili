# 特殊元素类（百大图形 27-36）

> 来源：H05 第 1-9 页、H06 第 1-3 页（讲义手写批注）+ L05-L06 讲 PPT。
> 本章第一性原理：**图形里出现了「自带含义」的元素（字、字母、数字、logo、立体、线、圆、标记点），规律就锁在这类元素的专属属性上。** 特殊元素类靠「认得它是什么」，不是靠通用规律硬套。

## 一、识别信号

- 图形由**文字、字母、数字、logo、立体图、开放线、圆、标记点**构成；
- 元素本身有「形状以外的语义」（汉字有笔画、字母有曲直、数字有封闭面）；
- 题干常是**一条式序列**或**分组分类**；
- 选项也是同类特殊元素——先确定「这类元素能考什么」。

```
└ 标记元素

　　└ 两元素→位置关系
```

## 三、百大图形 27：文字型

**特征**：题干是汉字（或汉字式字形）。

**考点顺序**：横竖线 → 面数量 → 元素传递 → 部分数量。

### 3.1 案例 27.1.1 横竖线（2021 四川下半年）→ **A**

- 题干：采、杯、击、回、岨、?；选项：品、猷、罡、韭。
- 规律：纯横竖线构成，横竖线数 1→6。
- 三行：共性识图·所有图形均为文字 ｜ 细节定位·纯横竖线构成 ｜ 选图思维·口字型·便于命题。
- 批注：「纯直图形，没有其他元素干扰」「横竖线 1→6」。

### 3.2 案例 27.1.2 横竖线（2024 辽宁）→ **B**

- 题干：查、三、面、享、标、沣，六个分两类。
- 规律：横线数量 5 / 3；B（①③④ / ②⑤⑥）。
- 三行：共性识图·所有图形均为文字 ｜ 细节定位·纯横线构成 ｜ 选图思维·口字型·便于命题。
- 批注：「1、定量优于定性；2、『三』不是为了突出开放，而是突出横线」。

### 3.3 案例 27.1.3 面数量（2024 山东）→ **C**

- 题干：齐、蹴、鞠、淄、?；选项：国、桓、稷、博。
- 规律：封闭面数 1→5。
- 三行：共性识图·所有图形均为文字 ｜ 细节定位·口字型 ｜ 选图思维·口字型、日字型、目字型、田字型·便于命题。
- 批注：「面数量 1→5」。

### 3.4 案例 27.1.4 元素传递+部分数量（2024 山东）→ **A**

- 题干：单、蝉、蝴 ｜ 中、忠、?；选项：意、革、串、芯。
- 规律：同元素重复递加（单→蝉→蝴，虫字部件 1、2、3）；第二组上下结构递推。
- 三行：共性识图·所有图形均为文字 ｜ 细节定位·相同元素和构成 ｜（第三行本页未写）。
- 批注：「元素传递+组成数量 1、2、3」「忠——上下」「意——上中下」。

**易错**
- 汉字题先看「纯直不纯直」：纯横竖 → 数横竖线；有封闭 → 数面。
- 「定性」（曲直、开放）常被「定量」（横线数）压过，龙飞明确说「定量优于定性」。

## 四、百大图形 28：字母（数字）型

**考点**：对称 / 曲直 / 封闭 / 相同元素 / 位置。

### 4.1 案例 28.1.1 曲线元素数量+位置（2021 河北等九省）→ **D**

- 题干：3×3 字母矩阵（CKT/FSX/AZP、JVY/LCH/EMO、UNT/FBI/?）。
- 规律：每格 3 个字母，曲线字母数量 1 个，位置按左/中/右循环。
- 三行：共性识图·所有图形均为字母 ｜ 细节定位·字母数量均为 3 个 ｜（第三行本页未写）。
- 批注：「曲线元素数量 1 + 位置（左中右）」「封闭小写字母：abdegopq／纯曲字母：COSa／两部分：ij」。

### 4.2 案例 28.1.2 对称方式（2024 江苏 C）→ **C**

- 题干：M、S、D、N、A、?；选项：T、X、Z、K。
- 规律：轴对称、中心对称交替；D 与 A 被红笔加短竖线改造成轴对称。
- 三行：共性识图·所有图形均为字母 ｜ 细节定位·S 字母 ｜ 选图思维·S、N、Z·固有属性。
- 批注：「对称方式：轴对称、中心对称交替」。

### 4.3 案例 28.1.3 相同元素位置（2023 四川等八省）→ **A**

- 题干：ZHAQ→OH→HOU→UNV；VNG→CE→EAR→RUI；123→389→907→78；831→12→[?]→45。
- 规律：前图末位元素 = 后图首位元素。
- 三行：共性识图·所有图形均为字母（数字）｜ 细节定位·存在相同元素 ｜ 选图思维·选项元素一致·规律排他。
- 批注：「相同位置元素／前图末位元素=后图首位元素」。

### 4.4 案例 28.1.4 面数量（2021 甘肃等四省）→ **C**

- 题干：3446 / 4905 / 7891 / 16?9。
- 规律：每格 4 个数字的封闭面总数为 3。
- 三行：共性识图·所有图形均为数字 ｜ 细节定位·8 数字 ｜（第三行本页未写）。
- 批注：「面数量 3」。

### 4.5 拓展演练（2023 福建等四省）→ **B**

- 题干：THIS、HELLO、HAIR、?；选项：FAIR、BOOK、EYE、BYE。
- 规律：封闭字母数量 0→3。
- 三行：共性识图·所有图形均为字母 ｜ 细节定位·B 字母 ｜ 选图思维·选项元素不一致·规律排他。
- 批注：「1、字母数量不一致；2、C 选项纯直」——先排除干扰项。

**易错**
- 字母题先列「属性表」：曲直、封闭、对称、部分数，再逐项套。
- 字母大小写混排时，先统一按印刷体看，别按手写体。

## 五、百大图形 29：logo 型

**特征**：题干是纯黑图标/标志（话筒、喇叭、开关、云下载、店铺、购物车）。

**考点**：面数量 / 相同元素 / 对称 / 部分数量。

### 5.1 案例 29.1.1 部分数量（2022 四川雅安事业单位）→ **C**

- 六个图标分两类：按图形是否分离（部分数 2 / 3）；C（①③④ / ②⑤⑥）。
- 三行：共性识图·所有图形均为 logo ｜ 细节定位·图形分离 ｜（第三行本页未写）。
- 批注：「部分数量 2/3」。

**易错**
- logo 题不要看「像什么」，只看几何属性：几部分、几个面、对不对称。

## 六、百大图形 30：立体型（平面考法）

**特征**：题干出现立体图（立方体、棱锥、棱柱等），但按**平面要素**考。

**核心批注（H05 P005）**：
- 「降维：题干给 3 个立体图形 → 2 维的面；题干给 3 维立体图形 + 2 维的平面图形 → 线、点。」
- 「立体图形不要数体积/表面积，数面、线、点。」

### 6.1 案例 30.1.1 面数量（2021 福建、宁夏）→ **B**

- 规律：4+5=9，9+16=25（面数量求和）。
- 三行：共性识图·所有图形均为立体图形 ｜ 细节定位·面细化 ｜（第三行本页未写）。
- 批注：「面数量求和」「4+5=9」「9+16=25」。

### 6.2 案例 30.1.2 点数量（2021 河南等八省）→ **A**

- 规律：点数量 3→7（平面图与立体图交替，数顶点）。
- 三行：共性识图·含立体图形 ｜ 细节定位·平面立体结合 ｜ 选图思维·首位单面图·规律排他。
- 批注：「点数量 3→7」。

**易错**
- 立体图的「面」是**外表面**，不是切割线围出的面。
- 立体+平面混排时，先判断「降维到哪一维」：全是立体 → 面；立体+平面 → 线/点。

## 七、百大图形 31：开放线

**特征**：线条不闭合（回旋折线、交叉线）。

### 7.1 案例 31.1.1 直角位置（2023 北京）→ **A**

- 规律：直角位置依次为右下、左下、左上、右上（逆时针轮转）。
- 三行：共性识图·所有图形均为回旋折线 ｜ 细节定位·均存在直角 ｜ 选图思维·折线数量相同·规律排他；平行线条·突出观感。
- 批注：「如果考平行，考进出口，但是不成规律；本题是用平行的强烈视觉观感来考垂直——垂直在图推中的呈现就是直角。」

### 7.2 案例 31.1.2 首尾点关系（2025 天津）→ **B**

- 规律：首尾点连线经过的线段数量为 2。
- 三行：共性识图·所有图形均为回旋折线 ｜ 细节定位·平行线或 Z 字型 ｜ 选图思维·折线数量不一致·规律排他。
- 批注：「首尾点连线经过线段数量 2」。

### 7.3 案例 31.2.1 特殊交点位置（2025 国考副省级）→ **D**

- 规律：十字交点位置：首条线段相交 / 中间线段相交。
- 三行：共性识图·所有图形均为交叉线 ｜ 细节定位·交叉线均为 3 条线段 ｜ 选图思维·交叉线线段数量相同·规律排他。

### 7.4 案例 31.2.2 曲直交点位置（2025 福建等八省）→ **D**

- 规律：曲直交点位置在曲线端点/中点交替。
- 三行：共性识图·所有图形均包含交叉线 ｜ 细节定位·曲线数量一致（1）且曲直交点数量一致（1）｜ 选图思维·曲线中点位置·突出观感。

### 7.5 拓展演练（2024 江苏 A/B/C）→ **B**

- 规律：圆圈标记的线段位置 1→6（沿罗盘式回旋线移动）。
- 三行：共性识图·所有图形均包含回旋折线 ｜ 细节定位·圆圈位置不同 ｜ 选图思维·罗盘式回旋形状·突出观感。

**易错**
- 回旋折线先看「直角/平行」的视觉观感，再看首尾点。
- 交叉线先数「几条线段」，线段数一致才看交点位置。

## 八、百大图形 32：相切圆

**考点**：切点数量 / 切点属性（一圆相切 / 两圆相切）/ 切线。

### 8.1 案例 32.1.1（2021 国考副省级、地市级）→ **C**

- 规律：切点数量为 1（每图恰好一个切点）。
- 三行：共性识图·所有图形均包含相切圆 ｜ 细节定位·圆数量一致（1）。

### 8.2 案例 32.1.2（2023 浙江）六个分类 → **A（①②⑤ / ③④⑥）**

- 规律：切点属性——①②⑤ 两圆相切，③④⑥ 一圆相切。
- 三行：共性识图·所有图形均包含相切圆 ｜ 细节定位·圆数量一致（2）。
- 批注：「切点属性：一圆相切/两圆相切」。

**易错**
- 相切圆先数圆，再数切点，最后看「切点属于哪个圆」。

## 九、百大图形 33：外接圆

**考点**：延伸线方向 / 圆位置。

### 9.1 案例 33.1.1 延伸线方向（2022 国考地市级、执法类）→ **C（①④⑤ / ②③⑥）**

- 规律：延伸线方向——①④⑤ 切线方向，②③⑥ 割线方向。
- 三行：共性识图·所有图形均包含外接圆 ｜ 细节定位·开放折线。
- 批注：「延伸线方向：切线方向/割线方向」。

**易错**
- 外接圆看「线出圆的方式」：擦边而过是切线，穿圆而过是割线。

## 十、百大图形 34：贯穿圆

**考点**：圆内要素（面数量）。

### 10.1 案例 34.1.1（2021 山东）→ **A**

- 规律：圆内面数量 1→6。
- 三行：共性识图·所有图形均包含贯穿圆 ｜ 细节定位·圆外半封闭。

## 十一、百大图形 35：封闭圆

**考点**：圆上点 / 圆内要素（面形状）。

### 11.1 案例 35.1.1（2022 甘肃等七省）六个分类 → **B（①②④ / ③⑤⑥）**

- 规律：圆内面形状是否存在三角形（①否，②是）。
- 三行：共性识图·所有图形均包含封闭圆 ｜ 细节定位·圆轮廓。
- 批注：「两圆相似，差在点」「都存在和外轮廓没有公共面的图形（两不沾，有点连接）」。

**易错**
- 封闭圆先看「圆内的面形状」，再看「面与轮廓是否共边」。

## 十二、百大图形 36：标记元素

**特征**：图中有**特殊的标记**（黑点、黑块、圆圈、加粗线）指向某个要素。

**两类**：
- 单/多元素标记 → 要素属性；
- 两个元素标记 → 要素关系。

### 12.1 案例 36.1.1 单元素·标记角（2022 浙江 A、C）→ **D**

- 规律：两条相交线标记的角是否为锐角；D（①④⑥ / ②③⑤），①④⑥ 非锐角、②③⑤ 锐角。
- 三行：共性识图·所有图形均包含标记元素 ｜ 细节定位·内部两条线 ｜ 选图思维·凹多边形·突出观感。
- 批注：「标记角属性／两条相交线标记角是否为锐角」。

### 12.2 案例 36.1.2 单元素·标记拐点（2023 浙江）→ **A**

- 规律：黑块与折线拐点完全对应。
- 三行：共性识图·所有图形均包含标记元素 ｜ 细节定位·黑块数量不同 ｜ 选图思维·均为 L 拐点·便于命题。
- 批注：「所有图形都是开放型折线轮廓→不存在交叉→规避十字交点」。

### 12.3 案例 36.2.1 两元素·标记面位置关系（2024 浙江）→ **C**

- 规律：两标记点的位置关系——①③⑥ 线连，②④⑤ 点连。
- 三行：共性识图·所有图形均包含标记元素 ｜ 细节定位·两个标记元素 ｜（第三行本页未写）。
- 批注：「标记面位置关系／线连/点连」。

### 12.4 案例 36.2.2 两元素·标记点样式关系（2025 天津）→ **D**

- 规律：标记交点属性——T 拐点 / T 字交点；①④⑤ T+T，②③⑥ T+L。
- 三行：共性识图·所有图形均包含标记元素 ｜ 细节定位·两个标记元素 ｜（第三行本页未写）。
- 批注：「标记交点属性／L 拐点、T 字交点」。

### 12.5 拓展演练（2025 国考副省级、执法类）→ **C**

- 规律：两标记连线方向垂直 / 平行；①②④ 垂直，③⑤⑥ 平行。
- 三行：共性识图·所有图形均包含标记元素 ｜ 细节定位·两类标记元素均各 2 个 ｜（第三行本页未写）。
- 批注：「标记连线方向关系／垂直/平行」。

**易错**
- 标记题的规律一定「落在被标记的那个要素上」，不要看没被标记的部分。
- 两个标记：先看「各自是什么」，再看「两者什么关系」。

## 十三、本章决策流

```
特殊元素出现
├ 汉字 → 横竖线 → 面数量 → 元素传递 → 部分数量
├ 字母/数字 → 对称 → 曲直 → 封闭 → 相同元素 → 位置
├ 图标/logo → 面数量 → 相同元素 → 对称 → 部分数量
├ 立体图 → 降维：全立体数面；立体+平面数线/点
├ 开放线
│  ├ 回旋折线 → 直角位置 / 首尾线方向 / 首尾点关系
│  └ 交叉线 → 特殊交点位置（线段数先一致）
├ 圆
│  ├ 相切圆 → 切点数量 / 切点属性 / 切线
│  ├ 外接圆 → 延伸线方向（切线/割线）/ 圆位置
│  ├ 贯穿圆 → 圆内要素（面数量）
│  └ 封闭圆 → 圆上点 / 圆内面形状
└ 标记元素
   ├ 单/多元素 → 要素属性（角、拐点、面）
   └ 两元素 → 位置关系（线连/点连、垂直/平行、T+T/T+L）
```

## 十四、本章口诀

- **特殊元素先认类，每类都有专属考点。**
- **汉字横竖面传递，字母曲直闭对称。**
- **logo 不看像什么，只看面数部分数。**
- **立体降维数面线点，贯穿圆只数圆内。**
- **相切数切点，外接看切线，封闭看圆内面。**
- **标记指哪看哪，两个标记看关系。**
