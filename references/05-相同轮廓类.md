# 相同轮廓类（百大图形 9-18）

> 来源：H02 第 7-11 页、H03 第 1-7 页（讲义手写批注）+ L03-L04 讲 PPT。
> 本章第一性原理：**轮廓相同 + 元素基本相同 = 元素在「同一个框架」里动。** 优先考虑「移动」，而不是数量/对称。

## 一、识别信号

- 所有图形的**外轮廓相同/相似**（同样的宫格、圆盘、蜂窝、线型、点阵、跳棋盘）；
- 图内元素的**种类和数量基本不变**，只是位置在变；
- 题干常是九宫格/类比型（三推三），或一条式序列；
- 选项之间往往「位置不同、元素相同」——这是移动题最典型的选项设置。

## 二、综合导图（H03 P007 原文）

```

 ├ 蜂窝型
 ├ 分离型

                     ├ 平移（行/列、环路、斜向）

综合导图（相同轮廓类）
├ 四宫格
│  ├ 元素不饱和→环路移动

├ 九宫格→环路移动
├ 十六以上宫格
│  ├ 元素少→环路移动
│  └ 元素多→整体移动
├ 米字型→位置关系/翻转/旋转
├ 环路型→单行（列）移动
├ 线型→平移/传送
├ 蜂窝型

└ 特殊型

```

## 三、先判断两件事

1. **元素是否饱和**（每个格子都有元素？）
   - 不饱和（有空格）→ 多为**环路移动**；
   - 饱和（填满）→ 多为**位置关系**或**整体移动**。
2. **轮廓是什么样式** → 决定移动路径（行/列、环路、斜向、传送带）。

## 四、百大图形 9：四宫格轮廓

### 4.1 元素不饱和 → 环路移动

- 案例 9.1.1（2021 北京）→ **B**。规律：元素沿四宫格外环移动。
- 案例 9.1.2（?）→ **D**。规律：元素不饱和，环路移动。
- 三行：共性识图·所有图形均含四宫格轮廓 ｜ 细节定位·元素不饱和 ｜ 选图思维·选项位置不同·规律排他；直角图形·便于命题。

### 4.2 元素饱和 → 位置关系

- 案例 9.2.1（2021 河南/湖北/湖南/吉林/江西/辽宁/内蒙古/青海/山西/陕西/云南）六个分类 → **A（①④⑥ / ②③⑤）**。规律：同图中均存在相同元素（相同元素位置关系）。
- 案例 9.2.2（?）→ **D**。规律：相邻图均存在相同元素。
- 拓展（嵌套）→ **A**。规律：元素位置不同且饱和。
- 三行：共性识图·所有图形均含四宫格轮廓 ｜ 细节定位·元素不同且饱和 ｜ 选图思维·分组题型·规律排他。

**易错**
- 饱和时还在找「空格移动」→ 应看元素之间的位置关系（相邻/相对/相同元素）。

## 五、百大图形 10：九宫格轮廓

**考法**：环路移动（元素沿九宫格外环/内环移动）。

- 案例 10.1.1（2021 安徽/河北/湖北/湖南/吉林/辽宁/内蒙古/青海/陕西/天津/云南/重庆）常规九宫格 → **D**。规律：元素数量一致且不饱和，环路移动。
- 案例 10.1.2 隐式九宫格 → **D**。规律：同上。
- 三行：共性识图·所有图形均含九宫格轮廓 ｜ 细节定位·元素数量一致且不饱和 ｜ 选图思维·选项位置不同·规律排他；同类元素位置关系不变·规律排他。

## 六、百大图形 11：十六以上宫格轮廓

### 6.1 元素数量少 → 分别移动

- 案例 11.1.1（2025 广东）内外环移动 → **B**。规律：内环逆时针 1 格、外环分别顺/逆时针。
- 案例 11.1.2 特殊环路移动 → **A**。规律：元素少且数量排布一致，特殊环路移动。
- 三行：共性识图·所有图形均含十六宫格轮廓 ｜ 细节定位·元素数量少且数量排布不一致 ｜ 选图思维·选项位置不同·规律排他；局部相同位置·规律排他。

### 6.2 元素数量多 → 整体移动

- 案例 11.2.1（2023 浙江）整体环路移动 → **A**。规律：二环整体逆时针 1 格、三环整体顺时针 2 格。
- 三行：共性识图·所有图形均含二十五宫格轮廓 ｜ 细节定位·元素数量多 ｜ 选图思维·一环元素一致·规律排他。

**龙飞批注**：
- 「一环元素一致·规律排他」——先找变化最小的那一环，用它锁定答案。
- 「局部相同位置·规律排他」——选项之间只有局部不同，规律就在那个局部。

## 七、百大图形 12：米字型轮廓

### 7.1 分组题型 → 元素相对位置

- 案例 12.1.1（2021 四川下半年）六个分类 → **B（①⑤⑥ / ②③④）**。规律：同元素是否顺序相邻（白白黑黑）。
- 龙飞批注：「不能考移动；移动的题型：单行推理、九宫格、三推三」。
- 三行：共性识图·所有图形均含米字型轮廓 ｜ 细节定位·元素相同且不饱和 ｜ 选图思维·分组题型·规律排他。

### 7.2 类比/九宫格题型 → 翻转/旋转

- 案例 12.2.1（2022 青海）→ **C**。规律：图一图二左右翻转，图二图三上下翻转。
- 三行：共性识图·所有图形均含米字型轮廓 ｜ 细节定位·元素相同且不饱和 ｜ 选图思维·类比/九宫格题型·规律排他。

**易错**
- 分组题不要套「移动」；分组题考的是**同一图内元素的关系**或**两组各自的共性**。
- 翻转 vs 旋转：翻转会改变左右/上下手性（像照镜子），旋转不会。看字母/箭头方向最快。

## 八、百大图形 13：环路型轮廓

**考法**：元素饱和时，按「单行/单列旋转 + 传递」移动。

- 案例 13.1.1（2023 国考副省级/执法类）→ **B**。规律：图1→图2 上行顺时针旋转 90°，图2→图3 右列顺时针旋转 90°，依次递推。
- 三行：共性识图·所有图形均含环路型轮廓 ｜ 细节定位·元素饱和 ｜ 选图思维·选项位置不同·规律排他；直角图形·便于命题。

**易错**
- 环路型 + 饱和：不是整个图旋转，而是**逐行/逐列**旋转并传递。

## 九、百大图形 14：线型轮廓

### 9.1 封闭式线型 → 平移

- 案例 14.1.1（2023 国考地市级）→ **A**。规律：每行元素平移 1 格并顺时针旋转 90°。
- 三行：共性识图·所有图形均含线型轮廓 ｜ 细节定位·封闭式 ｜ 选图思维·选项位置不同·规律排他；直角图形·便于命题。

### 9.2 开放式线型 → 平移 + 传送

- 案例 14.2.1（2024 广西/贵州/河南/湖南/云南）→ **A**。规律：传送式平移 1 格。
- 三行：共性识图·所有图形均含线型轮廓 ｜ 细节定位·开放式 ｜ 选图思维·选项位置不同·规律排他。

**龙飞 Tips**：两种路线——「单行移动路线」（三条向右箭头）与「传送移动路线」（蛇形往返箭头）。

**易错**
- 开放式线型的元素走到端点会「传送」到另一端，不是消失。

## 十、百大图形 15：蜂窝型轮廓

### 10.1 中心元素有规律 → 内外环移动

- 案例 15.1.1（2024 安徽/河北/江西/青海/山西/陕西/天津/新疆/重庆）→ **C**。规律：二环逆时针 1 格、三环顺时针 3 格。
- 案例 15.1.2（2024 国考副省级）→ **A**。规律：二环顺时针 1 格、三环逆时针 1 格。
- 三行：共性识图·所有图形均含蜂窝型轮廓 ｜ 细节定位·中心元素一致 ｜ 选图思维·选项位置不同·规律排他。
- 龙飞批注：「AB 相似，CD 相似，考虑移动」——选项成对相似时，规律大概率是移动。

### 10.2 中心元素无规律 → 斜向移动

- 案例 15.2.1（2022 四川）→ **C**。规律：左斜列向下平移 1 格。
- 案例 15.2.2（2024 国考地市级）→ **B**。规律：一二列左斜列向上 1 格、二三列右斜列向下 1 格。
- 三行：共性识图·所有图形均含蜂窝型轮廓 ｜ 细节定位·中心元素不一致 ｜ 选图思维·选项位置不同·规律排他。
- 龙飞批注：「看整体！」——中心不一致时，不要死盯中心，退一步看整体斜列。

**易错**
- 蜂窝型先看中心：中心一致 → 内外环；中心不一致 → 斜向。

## 十一、百大图形 16：分离型轮廓

**考法**：图形分成几个分离部分，**各部分分开移动**。

- 案例 16.1.1（2022 国考副省级/地市级）→ **A**。规律：上部图形环形逆时针 1 格，下部图形按行向左平移 1 格。
- 三行：共性识图·所有图形均含分离型轮廓 ｜ 细节定位·行元素排布是否一致 ｜ 选图思维·选项位置不同·规律排他。

**易错**
- 把分离型当整体移动；应分别追踪每一部分的路径。

## 十二、百大图形 17：点状型轮廓

**考法**：点阵中，线型/L 型等元素平移、旋转、翻转；注意**特殊交点**（L 型拐点、十字交点）的位置。

- 案例 17.1.1（2025 国考执法类）→ **C**。规律：线型元素外环逆时针 1 格；L 型元素顺时针旋转 90°，且拐点内环顺时针 1 格。
- 三行：共性识图·所有图形均含点状型轮廓 ｜ 细节定位·特殊交点（L 型拐点、十字交点）｜ 选图思维·选项位置不同·规律排他。

**易错**
- 只看整体方向，忽略「拐点」这个特殊点的位置。

## 十三、百大图形 18：特殊型轮廓

### 13.1 线连正方形 → 翻转/旋转/特殊交点位置

- 案例 18.1.1（2022 四川下半年）九宫格 → **D**。规律：一二列图形左右翻转，二三列图形上下翻转。
- 三行：共性识图·所有图形均含线连正方形 ｜ 细节定位·分离排布相同 ｜ 选图思维·选项单独方块·突出观感。

### 13.2 跳棋盘 → 位置关系

- 案例 18.2.1（2025 江苏 A）→ **A**。规律：两元素位置关系（相隔/条线）。
- 三行：共性识图·所有图形均含跳棋盘轮廓 ｜ 细节定位·六边形构成 ｜ 选图思维·两个元素·便于命题。
- 龙飞 Tips：跳棋盘两元素位置关系——相邻 / 隔线 / 隔位。

**易错**
- 跳棋盘不是宫格，不能按「行列平移」算，要按六边形的**相邻/隔线/隔位**关系。

## 十四、本章决策流

```
轮廓相同 + 元素基本相同
├ 先看元素是否饱和
│  ├ 不饱和 → 环路移动（四宫格/九宫格/十六宫格）
│  └ 饱和 → 位置关系 / 整体移动
├ 按轮廓分
│  ├ 四宫格：不饱和环路；饱和位置关系
│  ├ 九宫格：环路移动
│  ├ 十六以上：元素少分别移；元素多整体移
│  ├ 米字型：分组→位置关系；九宫格/类比→翻转/旋转
│  ├ 环路型：单行/列旋转+传递
│  ├ 线型：封闭→平移；开放→传送
│  ├ 蜂窝型：中心一致→内外环；中心不一致→斜向
│  ├ 分离型：分开移动
│  ├ 点状型：平移/旋转/翻转+特殊交点
│  └ 特殊型：线连正方形→翻转；跳棋盘→位置关系
└ 选项：位置不同→移动；元素不同→数量/叠加
```

## 十五、本章口诀

- **轮廓相同先想动，元素不变是移动。**
- **不饱和走环路，饱和看位置。**
- **十六宫格：少的分别移，多的整体移。**
- **蜂窝看中心：中心有规律走环，没规律走斜。**
- **分离分开移，线型看传送，跳棋看隔位。**
- **选项位置不同 → 移动；选项元素不同 → 数量/叠加。**
