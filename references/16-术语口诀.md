# 术语与口诀

> 术语按「龙飞课堂原义」解释；口诀来自各章讲义/PPT 原文，可直接背。

## 一、核心术语

### 1. 框架类

| 术语 | 含义 |
|---|---|
| 飞哥传书 | 龙飞的三行解题框架：共性识图 → 细节定位 → 选图思维 |
| 共性识图 | 找所有图形**共同具备**的局部特征，定大类（大前提） |
| 特征识图 | 修正图形类讲义的第一行写法，作用等同「共性识图」：先认出基础图形 |
| 细节定位 | 在共性里找**唯一在变**的细节，定规律（小前提） |
| 选图思维 | 用命题人设置选项的思路排他，定答案（结论） |
| 百大图形 | 龙飞把图形推理分为 100 个「图形样式」，每个样式对应固定考法 |
| 图形样式 | 百大下的细分，如 1.1、49.2 |
| 拓展演练 | 讲义中补充的真题，不计入百大案例号 |

### 2. 图形属性

| 术语 | 含义 |
|---|---|
| 面 | 封闭的空白区域；外轮廓本身不算面 |
| 单面图 | 只有一个封闭轮廓、内部无分割的图 |
| 开放图 | 线条不闭合、有端点的图 |
| 出头 | 线条伸出轮廓之外 |
| 悬空出头 | 出头的线不与其他线相连 |
| 分离型 | 图形由两个及以上互不相连的部分组成 |
| 点连 / 线连 | 两部分只共用一个点 / 共用一条边 |
| 对接边 | 两个面拼接时共用的那条边 |
| 重合区域 | 两个面重叠部分的形状 |
| 曲直交点 | 直线与曲线相交的点 |
| 切点 | 圆与圆/圆与线相切的那个点 |
| 奇点 | 从这个点出发的线条数为奇数的点 |
| 一笔画 | 连通图且奇点数为 0 或 2，可一笔画成 |
| 部分数 | 互不相连的图形块数；连在一起（含点连）算 1 部分 |
| 元素种类 | 形状/属性不同的元素类别数 |

### 3. 题型与问法

| 术语 | 含义 |
|---|---|
| 一条式 | 一串图形，问号在末尾或中间 |
| 两段式 | 前一组 → 后一组，规律相同或对应 |
| 九宫格 | 3×3（或 4×4），按行/列/对角看 |
| 分组分类 | 六个图分两类（①②③/④⑤⑥），两组各自成立 |
| 求异型 | 「哪一个与其他不同 / 除哪项外」 |
| 不可能型 | 三个可能 + 一个不可能 |
| 立体展开图 | 把立体表面摊平成平面图 |
| 相对面 | 立体中永不相邻的两个面（六面体） |
| 公共边 / 公共点 | 展开图折叠后重合的边 / 点 |
| 三视图 | 主视图、左视图、俯视图 |
| 隐藏视图 | 被遮挡后仍可能呈现的视图 |
| 截面 | 平面切过立体后得到的平面图形 |
| 层级切面 | 带上下层/斜面/凸台的立体切面；错在基础、方向、等长、对称 |
| 镂空切面 | 内部有孔洞的立体切面；先确认孔是否被切到 |
| 定点切面 | 过给定三点/三顶点的切面；用平行定位法 |
| 拼接 | 多块小立体拼成大立体；先数量，再处理特殊块 |

### 4. 命题人选项技术

| 术语 | 含义 |
|---|---|
| 突出观感 | 把考点做得视觉上最显眼，诱导你选「最像」的 |
| 规律排他 | 用另一条同样成立的规律排除干扰项 |
| 固有属性 | 图形天生具备、无需修饰的属性（对称/笔画/面） |
| 便于命题 | 把图形改成方便出题、方便设置干扰项的样子 |

### 5. 特殊基础图（修正类）

| 术语 | 含义 |
|---|---|
| 相交圆 ○○ | 两个圆相交，考交点数量 |
| 田字格 田 | 方框内十字，考 8 个直角/笔画 |
| 圆+又 ⊗ | 圆内交叉，考交点/面 |
| 圆+Y ⊙ | 圆内 Y 形，考面/笔画 |
| 圆+N ⊕ | 圆内 N 形，考轮廓线=面 |
| 圆+对号 ⊘ | 圆内对号，考面数量/形状 |
| 铜钱型 | 外圆内圆加放射线；固有属性「三不沾面」 |
| 锁芯型 | 多层嵌套，考面数量/对称/平行 |
| 笑脸型 | 圆脸+表情，考内部元素曲直/种类 |
| 三不沾面 | 一个面同时不碰内圆、外圆、斜线（铜钱型特征） |
| 奔驰型 | 三面共点，形似奔驰标；连接样式名，不等于笔画数 |
| 目字型 | 三面串联，形似「目」；连接样式名，不等于笔画数 |
| 日字型 | 方框内一横；常考修正/直角/笔画 |

## 二、各章口诀（原文）

### 第一章 规则图形类
- **规则先看对称，对称先看方式。**
- **纯中心没有轴，非纯中心可数轴。**
- **无斜轴看关系，有斜轴看方向。**
- **单面看轮廓，双面看拼接，内外看分离。**
- **局部特殊面：最大、最小、外轮廓、阴影面。**

### 第二章 封闭图形类
- **封闭先数面，面数定分支。**
- **数不一致看单调；不单调转一笔画/复合。**
- **=2 看对接，=3 看线连，≥4 看特殊面。**
- **三面线连：奔驰、目字、对号。**
- **黑白面：先面积，再位置；白多比白，白少比轮廓。**

### 第三章 相同轮廓类
- **轮廓相同先想动，元素不变是移动。**
- **不饱和走环路，饱和看位置。**
- **十六宫格：少的分别移，多的整体移。**
- **蜂窝看中心：中心有规律走环，没规律走斜。**
- **分离分开移，线型看传送，跳棋看隔位。**
- **选项位置不同 → 移动；选项元素不同 → 数量/叠加。**

### 第四章 黑白元素类
- **黑白题，先数块；连成片，看分割；散成沙，看数量。**
- **顶格数部分，离散数个数，整齐看对称。**
- **线连一笔画，点连看接法。**
- **单片规则数周长，不规则算面积（半格 0.5）。**
- **线穿格子数格数，又字交点看移动。**
- **三角聚合看位置，散开就数空白区。**

### 第五章 特殊元素类
- **特殊元素先认类，每类都有专属考点。**
- **汉字横竖面传递，字母曲直闭对称。**
- **logo 不看像什么，只看面数部分数。**
- **立体降维数面线点，贯穿圆只数圆内。**
- **相切数切点，外接看切线，封闭看圆内面。**
- **标记指哪看哪，两个标记看关系。**

### 第六章 相似图形类
- **相似图形做减法：哪里一样，哪里不一样。**
- **轮廓一样看叠加，形状一样看旋转，类型一样数要素。**
- **黑白叠加先定则，缺口空白也算色。**
- **九宫格先分行列，去同存异先验证。**
- **基础相同看排布，位置相同看遍历。**
- **复杂生活化，简化成要素；翻转看手性，旋转看角度。**

### 第七章 特征图形类
- **特征图形认特征，局部属性定考点。**
- **生活化不数数，先看曲直和开闭。**
- **出头悬空数交点，类圆出头数曲直，乱线出头数笔画。**
- **首开放数面，首单面数线，中间单面数直角。**
- **纯直平行数组数，直角三角数直角。**
- **分离图形算笔画，九宫中心看对角。**

### 第八章 复合考点类
- **一个规律排不完，两个规律一起看。**
- **复杂单调看并列，复杂不单调看作差。**
- **多要素作差，单要素看直角/笔画。**
- **对称配数量，移动配数量，叠加配旋转，黑白配翻转。**
- **十字数横竖，曲线数曲直，乱线数轮廓与交点。**

### 第九章 修正图形类
- **先认基础图，再看修正处。**
- **加线数交点，加框数面数，改形看边数，改性看笔画。**
- **铜钱看三不沾，锁芯看面数，笑脸看种类，对号看面形。**
- **对比修正找唯一：形状、数量、位置、属性、方向。**
- **选项有歧义，回题干找唯一属性。**

### 第十章 立体图形类
- **展开图看相邻，视图看投影。**
- **六面体找相对，四面体找公共顶点，八面体找公共边。**
- **异面体量边，积木看阴影，拼合先完整面。**
- **有相同面先找异面，组合体先找完整体。**
- **视图先轮廓后内线，隐藏视图数层数。**
- **切面「切一刀」，错在基础/方向/等长/对称；空心先看孔，定点用平移。**
- **拼接逐层数，特殊块先放；标记看阴影，相同看数量与对称。**

## 三、三行输出模板（背下来）

```
共性识图·所有图形均 ______
细节定位·在 ______ 上，______ 成规律
选图思维·______（突出观感/规律排他/固有属性/便于命题）
```

## 四、做题顺序口诀

**先定性，再定量；先整体，再局部；先简单，再复合；先贯穿，再排他。**
