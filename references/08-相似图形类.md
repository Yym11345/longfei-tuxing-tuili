# 相似图形类（百大图形 37-41）

> 来源：H06 第 4-11 页（讲义手写批注）+ L06-L07 讲 PPT。
> 本章第一性原理：**图形长得像 → 规律藏在「同」与「异」的对照里。** 先找「哪里一样」（相似点），再找「哪里不一样」（相异点），答案就在差异的维度上。

## 一、识别信号

- 题干图形**彼此高度相似**（轮廓一样、形状一样、元素类型一样、位置结构一样）；
- 相似之中有细微差别（数量、方向、角度、种类、排布）；
- 常见题型：九宫格、类比（三推三）、分组分类；
- 选项往往与题干「同款不同细节」。

## 二、综合导图（H06 P011 原文）

```
【飞哥传书】 相似图形类 ⇨ 根据［相似点］和［相异点］索引规律

综合导图（相似图形类）
├ 轮廓同、元素数量不同 ——（九宫格题型／类比题型）→ 黑白运算
├ 形状似、构成要素不同
│　├ 九宫格、类比题型→同异叠加
│　└ 分组题型→元素种类
├ 形状同、角度方向不同→旋转/翻转
├ 类型同、构成要素不同→要素数量
├ 元素同、位置排布不同→元素数量/位置关系
└ 位置同、具体分布不同→遍历/要素数量
```

## 三、先判断两件事

1. **「像」在哪一层？**
   - 轮廓像 → 叠加/运算；
   - 形状像 → 旋转/翻转、同异叠加；
   - 类型像（都是人/都是笑脸）→ 数要素；
   - 结构像（内外、上下、位置一样）→ 数量/位置关系/遍历。
2. **「变」在哪一层？** 数量变、方向变、种类变、分布变——只盯变化的那一层，不要全图重看。

**龙飞方法论**：相似题不是「找规律」，是「做减法」——两图逐项对比，剩下的差异就是考点。

## 四、百大图形 37：黑白叠加

**特征**：轮廓一致，但阴影数量不一致；前两图叠加得第三图。

### 4.1 轮廓一致、阴影数量不一致 → 黑白运算

- 案例 37.1.1（2022 甘肃/广西/河南/湖南）→ **C**。规律：白+白=白，黑+黑=白。
  - 三行：共性识图·所有图形均由黑白元素构成 ｜ 细节定位·黑球数量多且数量不一致 ｜ 选图思维·图 5 排布·规律排他；类比题型·便于命题。
  - 批注：「太特殊了，不适合考黑白分割」——元素太密时，直接走叠加。
- 案例 37.1.2（2025 江苏 B）九宫格 → **C**。规律：黑+黑=白，白+黑=黑（按行叠加）。
  - 三行：共性识图·所有图形均由黑白元素构成 ｜ 细节定位·每行轮廓相同且阴影数量多且数量不同 ｜ 选图思维·九宫格题型·便于命题。

### 4.2 轮廓含缺口、阴影数量不一致 → 黑白空叠加

- 案例 37.2.1（2023 浙江）→ **C**。规律：黑+白=黑（带缺口叠加）。
  - 三行：共性识图·所有图形均由黑白元素和缺口构成 ｜ 细节定位·缺口数量和黑块数量多且不一致 ｜ 选图思维·类比题型·便于命题。
  - 批注：「黑的数量远超于白——一般考标记，是标记的元素要少」。
- 案例 37.2.2（2024 国考副省级、执法类）九宫格 → **B**。规律：黑+白=白，黑+黑=空。
  - 三行：共性识图·所有图形均由黑白元素和缺口构成 ｜ 细节定位·缺口数量和黑块数量多且不一致 ｜ 选图思维·九宫格题型·便于命题。

**易错**
- 黑白运算必须先「定规则」：用第一组前两图逐格验证，再套第二组。
- 出现「缺口/空白」时，第三种颜色（空）也参与运算，别漏。

## 五、百大图形 38：形状叠加

**特征**：形状相似，构成要素不同；按行/列做「同异叠加」。

### 5.1 形状相似 → 同异叠加

- 案例 38.1.1（2024 安徽/河北/湖北/江西/山西/陕西/天津/新疆/重庆）九宫格 → **D**。规律：按列去同存异。
  - 三行：共性识图·每列图形形状相似 ｜ 细节定位·元素减少（缺失）｜ 选图思维·九宫格题型·便于命题。
- 案例 38.1.2（2023 内蒙古）九宫格 → **C**。规律：按行同异叠加。
  - 三行：共性识图·每列图形形状相似 ｜ 细节定位·元素减少（缺失）｜ 选图思维·九宫格题型·便于命题。

### 5.2 元素种类相同且行/列减 1 → 形状叠加

- 案例 38.2.1（2021 福建/湖南/宁夏/新疆建设兵团）→ **B**。规律：十+星=星，星+星=十（两种元素交替转换）。
  - 三行：共性识图·所有图形均由两种元素构成 ｜ 细节定位·列数减一 ｜ 选图思维·宫格递推题型·便于命题。

**易错**
- 「去同存异 / 去异存同 / 直接叠加」是三种不同规则，先用第一组验证是哪种。
- 九宫格先判断「按行」还是「按列」——看哪一方向的规律能贯通三行/三列。

## 六、百大图形 39：相似生活化图形

**特征**：图形是「生活化」的（松枝、笑脸、小人），复杂且相似。

### 6.1 图形复杂且相似 → 翻转/旋转

- 案例 39.1.1（2024 江苏 A、C）九宫格 → **B**。规律：每行前两幅逆时针旋转 90°，后两幅上下翻转。
  - 三行：共性识图·每行图形均由相似生活化图形构成 ｜ 细节定位·图形复杂 ｜ 选图思维·九宫格题型·便于命题。

### 6.2 图形相似且分组 → 元素种类

- 案例 39.2.1（2022 山东）六个笑脸分两类 → **D（①③⑤=2 / ②④⑥=1）**。规律：轮廓内元素种类数。
  - 三行：共性识图·每行图形均由相似生活化图形构成 ｜ 细节定位·笑脸图形 ｜ 选图思维·分组题型·便于命题。

### 6.3 同类型元素 → 要素数量

- 案例 39.3.1（2024 山东）→ **D**。规律：直线数量 5→10。
  - 三行：共性识图·每行图形均由同类型元素构成 ｜ 细节定位·人形图形 ｜（第三行本页未写）。

**易错**
- 生活化图形「越复杂越要简化」：数元素种类、数直线、看旋转，不要试图理解画面内容。
- 旋转 vs 翻转看「手性」：翻转后左右会互换，旋转不会。

## 七、百大图形 40：基础构成相同

**特征**：所有图形由**相同的几个基础图形**拼成（等边三角形、圆、长方形）。

**考点**：形状排布 / 位置关系。

- 案例 40.1.1（2021 江苏 B、C）→ **D**。规律：均由 4 个相同等边三角形构成，看排布/重叠。
  - 三行：共性识图·所有图形相同基础构成 ｜ 细节定位·等边三角形构成 ｜ 选图思维·数量相同·突出观感。
- 案例 40.1.2（2022 山东）→ **B**。规律：三个圆的位置关系（两圆相切 / 无相切 / 三圆两两相切）。
  - 三行：共性识图·所有图形相同基础构成 ｜ 细节定位·圆形构成 ｜ 选图思维·数量相同·突出观感。
- 案例 40.1.3（2025 江苏 A、C）→ **C**。规律：横竖长方形排布——整体三横两竖，单独长方形横竖交替。
  - 三行：共性识图·所有图形相同基础构成 ｜ 细节定位·长方形 ｜ 选图思维·数量相同·突出观感。

**易错**
- 基础构成相同 → 数量已经不是考点（都一样），要看**排布方式**和**位置关系**。

## 八、百大图形 41：位置构成相似

**特征**：图形的「位置结构」相同（内外、上下），但具体元素/分布不同。

**考点**：遍历 / 要素数量关系。

- 案例 41.1.1（2021 山东）九宫格 → **B**。规律：行元素遍历——多边形为长方形、梯形、三角形且旋转；元素两内、两外、黑外白内。
  - 三行：共性识图·所有图形相同位置构成 ｜ 细节定位·内外排布 ｜ 选图思维·九宫格题型·便于命题。
- 案例 41.1.2（2023 黑龙江/辽宁/内蒙古）六个分类 → **B（①③④ 多 1 个 / ②⑤⑥ 相等）**。规律：内外元素数量关系。
  - 三行：共性识图·所有图形相同位置构成 ｜ 细节定位·内外排布 ｜ 选图思维·相同轮廓·突出观感。
- 案例 41.1.3（2023 江苏 A、B）→ **C**。规律：上下位置关系 + 笔画数量 3。
  - 三行：共性识图·所有图形相同位置构成 ｜ 细节定位·上下排布 ｜ 选图思维·箭头、田字格、奔驰型·固有属性。
- 拓展演练（2025 山东）六个分类 → **B**。规律：旋转——123 为同图形不同旋转角度，456 为同图形不同旋转角度。
  - 三行：共性识图·所有图形相似位置构成 ｜ 细节定位·1 图 6 图对比 ｜（第三行本页未写）。

**易错**
- 位置构成相似，先分「内/外」「上/下」，再比两层的元素数量。
- 遍历题：每一行/列元素种类齐全，缺什么补什么。

## 九、本章决策流

```
图形高度相似
├ 轮廓同、阴影数量不同 → 黑白运算（定规则：白+白、黑+黑、黑+白、空）
├ 形状似、构成要素不同
│  ├ 九宫格/类比 → 同异叠加（去同存异/去异存同/叠加）
│  └ 分组 → 元素种类
├ 形状同、角度方向不同 → 旋转/翻转（看手性辨翻转）
├ 类型同、构成要素不同 → 要素数量（直线数、元素数）
├ 元素同、位置排布不同 → 元素数量 / 位置关系
└ 位置同、具体分布不同 → 遍历 / 要素数量（内vs外、上vs下）
```

## 十、本章口诀

- **相似图形做减法：哪里一样，哪里不一样。**
- **轮廓一样看叠加，形状一样看旋转，类型一样数要素。**
- **黑白叠加先定则，缺口空白也算色。**
- **九宫格先分行列，去同存异先验证。**
- **基础相同看排布，位置相同看遍历。**
- **复杂生活化，简化成要素；翻转看手性，旋转看角度。**
