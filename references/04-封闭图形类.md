# 封闭图形类（百大图形 4-8）

> 来源：H01 第 9-13 页、H02 第 1-6 页（讲义手写批注）+ L02-L03 讲 PPT。
> 本章第一性原理：**纯封闭图形，视觉上最突出的是「面」。** 先数面，面数定了，再看面的形状和位置。

## 一、识别信号

- 图形全部由封闭线条构成，没有开放线、没有立体；
- 第一眼看到的是「一块一块的空白区域」；
- 题干常出现「面数量 2→7」「面数量 4/2」这类手写标注；
- 图形复杂程度递增/递减，或面数相同但形状不同。

## 三、百大图形 4：面数量不一致

**识别**：图形面数不固定，且没有「面数相同」的明显特征。

**四条分支（按顺序判断）**：

1. **复杂程度单调增减** → 直接数面，看 2→3→4→5→6→7 或递减。
   - 典型：案例 4.1.1（2021 四川下半年）→ **A**，面数量 2→7。
   - 典型：案例 4.1.2（2022 青海）生活化线描（公文包、显示器、热气球…）→ **B**，面数量 2→7。
2. **含中心对称图形** → 面数量常为固定值（如 4）。
   - 龙飞批注：「中心对称图形：形状规则，有相同面」。
   - 典型：案例 4.2.1（2022 江苏 C）→ **D**，面数量 4，且题干都是「曲+直」。
   - 典型：案例 4.2.2（2021 国考副省级/地市级）六个分类 → **C（①③④ / ②⑤⑥）**，面数量 2 / 4。
  - 典型：案例 4.2.3（2022 安徽等十一省）六个分类 → **D（①⑤⑥ / ②③④）**，面数量 6 / 9，均含中心对称图。Tips 原文：含中心对称图考察面数量，是利用中心对称图面形状相同的特点，定出「面」的视觉观感。
3. **内外不规则且数量不单调** → 转**一笔画**（见 09-特征图形类）。
4. **轮廓规则且数量不单调** → 转**复合考法**（对称轴数量 ± 面数量等，见 09-特征图形类）。

**易错**
- 数面数错：把「外部大轮廓」当成一个面（只数封闭的空白区域，不数外框本身）。
- 面数不单调就放弃：应转一笔画或复合考法，而不是继续硬数。
- 生活化图形不敢数：生活化图形也是面，照数。

## 四、百大图形 5：面数量相同（=2）→ 对接考法

**识别**：图形由**两个面**组成，且两面相连。

**基础前言（原文）**：
> 2 面线连：面形状规则 → 对称考法；面形状不规则 → 对接考法。
> 【对接考法】对接方式、对接边数量、对接边曲直、对接边方向、对接边长短。

**五个对接维度**：
| 维度 | 看什么 |
|---|---|
| 对接方式 | 点连 / 线连；公共边是整条还是部分 |
| 对接边数量 | 公共边是 1 条还是 2 条 |
| 对接边曲直 | 公共边是直线还是曲线 |
| 对接边方向 | 公共边横 / 竖 / 斜 |
| 对接边长短 | 长边 / 短边；等长 / 不等长 |

**典型例题**
- 案例 5.1.1（2021 国考副省级/地市级）六个分类 → **D（①⑤⑥ / ②③④）**。规律：对接边数量 1 / 2。三行：共性识图·所有图形均纯封闭 ｜ 细节定位·2 面线连图形 ｜ 选图思维·不规则·规律排他。
- 案例 5.1.2（2025 山东）六个分类 → **C（①②⑤ / ③④⑥）**。规律：对接边长短（短边 / 长边）。三行：…｜细节定位·2 面线连图形 ｜ 选图思维·对角线·固有属性；中心对称·规律排他。

**易错**
- 把「对接边」看成「图形边」：只数两个面共用的那条边。
- 两个面大小相近时，忽略「长边/短边」的差别。

## 五、百大图形 6：面数量相同（=3）

**基础前言（原文）**：【3 面线连】线连方式、重合形状、特殊形状。

### 5.1 外轮廓不规则 → 线连方式

**三种连接样式**（龙飞口诀）：
- **奔驰型**（Y 型）：三个面从一个公共点向外发散；
- **目字型**：三个面排成「日/目」字形，两两共边；
- **对号型**：三个面呈「✓」状排列。

**典型例题**
- 案例 6.1.1（2020 国考地市级）六个分类 → **A（①④⑥ / ②③⑤）**。规律：**内部线数量 4 / 3**（4 条=并联式，3 条=串联式）。三行：共性识图·所有图形均纯封闭 ｜ 细节定位·3 个面且轮廓不规则 ｜ 选图思维·奔驰型修正·固有属性。
  - **批注存疑**：H01 红字写「125（奔驰型）/346（目字型）」，与红勾答案 A 的分组（146/235）不一致。做题以「内部线数量」为准，奔驰/目字仅作连接样式名，不要据此数笔画。

### 5.2 均为「目」型连接 → 重合形状

**考法**：三个面重合区域的形状——四边形 / 五边形 / 三角形等。

- 案例 6.2.1（2025 浙江）六个分类 → **C（①④⑥ / ②③⑤）**。规律：重合区域四边形 / 五边形。三行：…｜细节定位·3 个面且呈「目」型连接（重合样式）｜ 选图思维·重合样式·突出观感。

### 5.3 外轮廓规则 → 特殊形状

**考法**：
- 三角形数量（如 2 个三角形 + 1 个四边形）；
- 相同面 / 相似面 / 最大面 / 最小面；
- 面的形状种类（2 种 / 3 种）。

**典型例题**
- 案例 6.3.1（2021 浙江 A/B/C）去掉一个 → **B**。规律：面形状 2 个三角形 / 1 个四边形。三行：共性识图·所有图形均纯封闭 ｜ 细节定位·3 个面且外轮廓规则 ｜ 选图思维·轮廓规则·突出观感；点延伸线·便于命题。
- 案例 6.3.2（2025 浙江）六个分类 → **C（①③④ / ②⑤⑥）**。规律：面形状种类 2 / 3。三行：…｜细节定位·3 个面且外轮廓规则 ｜ 选图思维·相同面构成·突出观感。

**易错**
- 只数三角形，漏掉四边形/五边形；
- 「相同面」需形状+大小都相同，「相似面」只需形状相似（大小可不同）。

## 六、百大图形 7：面数量相同（≥4）

**基础前言（原文）**：【多面线连】特殊面、相同面、相似面、对称面。

### 6.1 外轮廓规则 → 特殊面 / 相同面 / 相似面 / 对称面

| 考法 | 识别 | 例 |
|---|---|---|
| **三角形数量** | 图内有很多三角形，大小不明显 | 案例 7.1.1（2022 国考副省级/地市级）→ **D（①③⑥/②④⑤）**，三角形数量 4/3 |
| **三角形数量（递增）** | 三角形从无到有 | 案例 7.1.2（2024 甘肃/广西/河南/湖南/云南）→ **B**，0→5 |
| **相似面** | 大小面明显，形状相同 | 案例 7.1.3（2022 国考副省级/执法类）→ **C**，大小面相似 |
| **相同面** | 存在两个完全相同的面 | 拓展（2022 北京）→ **B**，每图均含两个相同面 |
| **对称面** | 面本身轴对称/中心对称 | 参见案例 2.3.1、2.3.2（规则图形类） |

**龙飞批注**：
- 「大小面不明显（和相似面无关）·规律排他」；
- 「点延伸线·便于命题」——图形中的点会向外延伸出线，形成更多面，是命题人常用的画图手法。

### 6.2 多面点连 → 点连方式

**识别**：面与面之间不是共边，而是**点连接**（顶点相接）。

**考法**：
- **顺序点连**（串联）：面依次相接成链；
- **并联**：多个面共用一个点。

**典型例题**
- 案例 7.2.1（2023 广西）六个分类 → **D（①④⑥ / ②③⑤）**。规律：点连（顺序/并联）。三行：共性识图·所有图形均纯封闭 ｜ 细节定位·4 个面且点连 ｜ 选图思维·形状不规则·规律排他。

**易错**
- 点连和线连混淆：看两个面是「共边」还是「只共一个点」。
- 多面题先数面，面数相同再点连方式。

## 七、百大图形 8：黑白面

**基础前言（原文）**：【黑白面·图形关系】面积关系、与轮廓位置关系、与白面位置关系。

### 7.1 阴影均含等腰直角三角形 → 面积关系

**识别**：阴影部分由等腰直角三角形构成（或可拼成），轮廓规则。

**考法**：阴影面积占整体的比例（1/2、1/3、1/4…），或阴影面积与白面面积的关系。

- 案例 8.1.1（2021 北京）→ **B**。规律：阴影面积占比 1/2。
- 案例 8.1.2（?）→ **D**。规律：阴影均含等腰直角三角形且轮廓规则。

**三行**：共性识图·所有图形均纯封闭 ｜ 细节定位·阴影均含等腰直角三角形且轮廓规则 ｜ 选图思维·等腰直角三角形或相似图形·便于命题。

### 7.2 一黑多白（白≥4）→ 黑白面位置关系

**识别**：一个黑面 + 多个白面（白面 ≥4）。

**考法**：黑面与白面的位置关系——是否相邻、是否分离、黑面被几个白面包围。

- 案例 8.2.1（?）→ **C**。规律：1 黑 4 白且外轮廓不一致。
- 案例 8.2.2（2024 国考副省级/地市级/执法类）六个分类 → **D（①②③ / ④⑤⑥）**。规律：是否存在一个白面与黑面分离。

**三行**：共性识图·所有图形均纯封闭 ｜ 细节定位·1 黑 4 白且外轮廓不一致 ｜ 选图思维·外轮廓不一致·规律排他。

### 7.3 一黑多白（白<4）→ 与轮廓位置关系

**识别**：一个黑面 + 少量白面（白面 <4）。

**考法**：黑面与**外轮廓**的位置关系——黑面在角上/边上/内部；黑面与轮廓的公共边数量。

- 案例 8.3.1（?）→ **C（①③⑥ / ②④⑤）**。规律：1 黑 3 白且外轮廓不一致。
- 案例 8.3.2（?）→ **A（①②⑥ / ③④⑤）**。规律：基本 1 黑 3 白且外轮廓不一致。
- 案例 8.3.3（?）→ **B**。规律：1 黑 1 白且外轮廓不一致。

**三行**：共性识图·所有图形均纯封闭 ｜ 细节定位·1 黑 3 白且外轮廓不一致 ｜ 选图思维·外轮廓不一致·规律排他；阴影不规则·规律排他。

**易错**
- 黑白面题先数黑面/白面数量，数量不通再转位置关系。
- 「白≥4」和「白<4」是两条不同分支，不要混用。

## 八、本章决策流

```
纯封闭图形
├ 面数量不一致
│  ├ 复杂程度单调 → 数面（2→7）
│  ├ 含中心对称 → 面数量固定（常为4）
│  ├ 内外不规则且不单调 → 一笔画
│  └ 轮廓规则且不单调 → 复合考法
├ 面数量=2 → 对接考法（方式/边数/曲直/方向/长短）
├ 面数量=3
│  ├ 轮廓不规则 → 线连方式（奔驰/目字/对号）
│  ├ 目字型 → 重合形状
│  └ 轮廓规则 → 特殊形状（三角形数量/相同面/相似面）
├ 面数量≥4
│  ├ 轮廓规则 → 特殊面（相同/相似/对称/最大/最小）
│  └ 点连 → 点连方式（顺序/并联）
└ 黑白面
   ├ 阴影含等腰直角三角形 → 面积关系
   ├ 1黑多白（白≥4）→ 黑白面位置关系
   └ 1黑多白（白<4）→ 与轮廓位置关系
```

## 九、本章口诀

- **封闭先数面，面数定分支。**
- **数不一致看单调；不单调转一笔画/复合。**
- **=2 看对接，=3 看线连，≥4 看特殊面。**
- **三面线连：奔驰、目字、对号。**
- **黑白面：先面积，再位置；白多比白，白少比轮廓。**
