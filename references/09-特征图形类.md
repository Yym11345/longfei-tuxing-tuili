# 特征图形类（百大图形 42-55）

> 来源：H07 第 1-9 页、H08 第 1-8 页（讲义手写批注）+ L07-L08 讲 PPT。
> 本章第一性原理：**图形「不按常规形状出牌」——生活化、出头、开放、单面、分离、平行、直角、纯曲直。规律不在整体形状，而在这些局部特征自带的属性上。** 龙飞原话：「根据局部特征图探索验证规律」。

## 一、识别信号

- 图形是**生活化物件**、**带出头线**、**首位开放/单面**、**内外复杂**、**分离**、**纯直/纯曲**；
- 图形「不规则、不像规则几何」，但每幅都有同一个**显眼局部特征**；
- 常见问法：一条式、九宫格、分组分类；
- 选项与题干同款特征——先找「所有图都有的那个局部特征」。

## 二、综合导图（H08 P008 原文）

```
【飞哥传书】 特征图形类 ⇨ 根据局部特征图探索验证规律

综合导图（特征图形类）
├ 形状特征
│  ├ 含纯曲直图形→曲直定性/定量
│  ├ 含对称图形→相同元素
│  ├ 含复杂出头图形→封闭属性
│  ├ 含悬空出头图形→交点数量
│  ├ 含类圆曲线出头图形→曲直交点/切点
│  ├ 含不规则出头图形→一笔画
│  ├ 含不规则封闭图形→一笔画
│  ├ 含平行特征图形→平行线
│  └ 含直角三角形构成图形→直角
├ 位置特征
│  ├ 含点连接图形→一笔画/连接方式
│  ├ 含分离图形→一笔画/相同元素/曲直定性
│  ├ 开放图首位→面数量/交点/一笔画
│  ├ 单面图首位→要素定性/定量/一笔画
│  └ 单面图中间位→直角/线/一笔画
├ 组合特征
│  ├ 单面元素+开放元素组合→开闭元素关系
│  └ 两种元素+单元素组合→元素种类数量关系
└ 九宫格题型特征
   ├ 中心位置数量特征→对角数量关系
   └ 中心位置形状特征→对称
```

## 十二、百大图形 50：平行特征图

**特征**：图形纯直，含明显平行线（平行轮廓、内部 N 字型、相似构成）。

**考法**：平行线组数。

- 案例 50.1.1（2022 江苏 A）九宫格 → **C**。规律：每行平行线组数 1/2/3。
  - 三行：共性识图·所有图形均包含平行特征 ｜ 细节定位·纯直。
  - 批注：「相似图」指向第一行第三图，「平行轮廓」指向第三行第一图。
- 案例 50.1.2（2024 浙江）六个分类 → **B（①②⑥=1 组 / ③④⑤=2 组）**。
  - 批注：「N 字型」指向④；另注「一笔画④⑤⑥／两笔画①②③／但是没有该选项」。

**易错**
- 平行线题只数「组数」，不数条数；N/Z 字型是典型 1 组平行。

**特征**：图形由纯曲线或纯直线构成（曲直图形 ≥3）。

**考法**：曲直定性/定量。

- 案例 52.1.1（2021 江苏 A、C）九宫格 → **D**。规律：第一列纯直、第二列纯曲、第三列曲直结合。
- 案例 52.1.2（2023 江苏 A、B）九宫格 → **A**。规律同 52.1.1。

  - 批注：「曲线不规则，考不了定量」——曲线不规则时只能定性。

**考法**：一笔画（分离部分数 → 笔画数）。

## 十六、百大图形 54：九宫格中心特征图

**特征**：九宫格中心格有特殊元素/数量。

## 十八、本章决策流

```
图形带局部特征
├ 生活化物件 → 曲直定性 → 连接方式 → 一笔画 → 相同元素 → 封闭属性
├ 出头
│  ├ 悬空 → 交点数量
│  ├ 类圆曲线 → 曲直交点 / 切点 / 交点位置
│  └ 不规则 → 一笔画
├ 首位开放 → 面数量 / 交点 / 一笔画
├ 首位单面 → 曲直定量 / 一笔画
├ 中间单面 → 直角数量 / 线 / 一笔画
├ 单面+开放组合 → 开闭元素数量
├ 两种元素+单元素 → 两类元素数量差
├ 内外复杂 → 一笔画
├ 纯直带平行 → 平行线组数
├ 含直角三角形 → 直角数量
├ 纯曲/纯直 → 曲直定性（曲线不规则不数数）
├ 分离 → 一笔画（各部分笔画和）
├ 九宫格中心特殊 → 对角数量 / 对称轴指向中心
└ 复杂分离 → 元素种类 / 曲直定性
```

## 十九、本章口诀

- **特征图形认特征，局部属性定考点。**
- **生活化不数数，先看曲直和开闭。**
- **出头悬空数交点，类圆出头数曲直，乱线出头数笔画。**
- **首开放数面，首单面数线，中间单面数直角。**
- **纯直平行数组数，直角三角数直角。**
- **分离图形算笔画，九宫中心看对角。**
