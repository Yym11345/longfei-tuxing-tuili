# 第一性原理：图形推理到底在考什么

> 本卷是「龙飞百大图形推理」体系的抽象层。龙飞原体系用「共性识图 / 细节定位 / 选图思维」三行讲每道题；本卷把这三行还原成可迁移的推理模型。原话与重构会明确区分。

## 一、一句话原理

**图形推理题，是命题人在图形的一个「可观察、可比较」的属性上，构造一条「可重复的变换规则」；解题就是先确定他动了哪个属性，再验证这条规则能否贯穿全部图形。**

所以做题不是「把所有规律试一遍」，而是：
1. 先判断这组图形「像什么」——它共同具备的视觉特征，决定了命题人**只能**在哪些属性上出题；
2. 再找「唯一在变的细节」——共性之上的差异，锁定具体规律；
3. 最后用选项验证——正确答案必须让规律贯穿所有图，并且是命题人「故意做得最像」的那个。

## 二、图形只有五个可考维度

任何一道图形推理题，变化都落在下面五类里（立体题是第五类）：

| 维度 | 具体内容 | 典型问法/表现 |
|---|---|---|
| 1. 元素属性 | 形状、曲直、开闭、对称、黑白、数量（点/线/面/素/角） | 图形长得不一样，但某一属性成序列 |
| 2. 位置关系 | 平移、旋转、翻转、相邻/相对/重合/分离 | 轮廓相同，元素在动 |
| 3. 组合关系 | 叠加、去同存异、黑白运算、拼接、相交、相切、包含 | 图形相似，元素在增删/运算 |
| 4. 数量关系 | 等差、等比、周期、交替、递推、和差倍比 | 数字感强，能数出稳定序列 |
| 5. 空间维度 | 展开/折叠、三视图、截面、立体拼合 | 立体图形、纸盒、积木 |

**第一性原理的用法**：拿到题，先问「这五个维度里，哪一个的解释成本最低」——不是找最复杂的规律，而是找**能解释全部图形且规则最简单**的那一个。

## 三、龙飞三段论 = 大前提 → 小前提 → 结论

龙飞每道题的「飞哥传书」三行，本质是一个三段论：

| 龙飞行 | 逻辑角色 | 要回答的问题 | 例（案例 1.1.1） |
|---|---|---|---|
| **共性识图** | 大前提 | 所有图形共同具备什么？ | 所有图形均规则 |
| **细节定位** | 小前提 | 共性之上，哪个细节在变？ | 包含纯中心对称图形 |
| **选图思维** | 结论/排他 | 哪个选项能让规律贯穿且唯一？ | 字母元素·固有属性 → 选 Z |

- **共性识图**决定「去哪个规律池找」；找错大类，后面全错。
- **细节定位**决定「池子里用哪一条」；这一步靠「唯一变量」。
- **选图思维**决定「答案长什么样」；命题人设置选项时会故意制造同构项，必须用规律排他。

## 四、命题人视角：选项是怎么挖坑的

龙飞讲义里反复出现四类「选图思维」，本质是命题人的四种手法：

1. **突出观感**：把要考的规律做得显眼（如「3 个相同面」「悬空线条」「黑白整行列排布」）。看到某个特征被刻意放大，优先怀疑它。
2. **规律排他**：几个选项在结构上相似，只有一个能让规律贯穿（如「AB 相似、CD 相似，考虑移动」）。
3. **固有属性**：利用图形自带的稳定属性设题（字母 S/N/Z 的中心对称、正多边形的对称轴数量、汉字的横竖线/封闭面）。这类题不需要复杂推理，只需要「认识图形」。
4. **便于命题**：命题人会选择容易画出、容易设置干扰项的图形（如「口字型」「日字型」「田字型」汉字、正多边形、九宫格）。看到这些「命题友好型」图形，优先想对应考点。

## 五、规律的四条检验标准

一条规律要成为答案，必须同时满足：

1. **贯穿性**：能解释题干中**每一个**图形，不能只解释前三个。
2. **唯一性**：在所有候选规律中，只有它能区分选项；如果两条规律都能选同一个答案，取更简单的那条。
3. **简洁性**：优先「一个变量」而不是「多个变量叠加」；优先「数数」而不是「复杂运算」。
4. **可复现性**：同样的规律能让你**预测**问号处应该长什么样，而不是看完选项后反推。

> 口诀：**共性定池，差异定路，选项定案，贯穿为准。**

## 六、卡住时的换维顺序

龙飞体系的隐含搜索顺序（从高频到低频）：

```
对称 → 面 → 移动 → 数量（点线面素角） → 曲直/开闭 → 一笔画 → 叠加/运算 → 位置关系 → 立体
```

但这个顺序不是死记的。正确用法是：
- **先按图形特征跳到你怀疑的维度**（规则图→对称；封闭图→面；相同轮廓→移动；黑白→分割/数量；相似→叠加；带局部特征→曲直/一笔画/直角/平行；数量忽大忽小→作差；基础图变体→修正；立体→空间）；
- 在该维度内**由简到繁**试 2-4 条规律；
- 两条都不通，再换维度，而不是在一个维度里死磕。

## 七、和「背规律」的区别

背规律的人：看到题 → 回忆「这题像哪个例题」→ 套。
第一性原理的人：看到题 → 判断「命题人动了哪个属性」→ 生成规律 → 验证。

百大图形是「索引」，不是「题库」。它的价值在于：**把「图形长什么样」和「命题人能考什么」建立映射**。真正做题时，先用共性识图归入某一类，再从该类的规律池里选，不需要记住 100 道题的具体图形。

## 八、边界说明

- 本卷及整个 skill 的原始材料只覆盖**图形推理**（百大图形 1-100），不包含定义判断、类比推理、逻辑判断。
- 「第一性原理」部分是编者对龙飞原体系的抽象重构；龙飞原话以各分卷中标注的「飞哥传书」三行为准。

## 九、附录：龙飞手写总体系（H12 P007 页末）

```
有背景
    轮廓(移动)
    黑白元素
    黑白运算 九宫格 3×3
无背景
    规则(对称)
    特殊元素(文字、字母、logo、折线)
    封闭
特征
    形状(出头、生活化、直角三角形、N字型…)
    位置(首开、单面…)
    数量(分布)
极具特征(具体)
    修正(圆+叉/圆+N…)
复合
    复杂程度 不单调
    简单复合
        规则
        封闭
```

> 这是龙飞在最后一册页末手写的总分类，可视为十章体系的「课前版」：**有背景** → 相同轮廓/黑白元素；**无背景** → 规则/特殊元素/封闭；**特征** → 特征图形类；**极具特征** → 修正图形类；**复合** → 复合考点类。原稿「首开」二字字迹如此，语义待核（或为「首末」）；「具体」或为「具象」。实际归类以十章体系为准。
