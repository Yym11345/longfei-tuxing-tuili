# 龙飞百大图推（longfei-tuxing-tuili）

中文名：**龙飞百大图推**（龙飞图形推理 · 百大图形体系）。把 11 讲 PPT、12 册讲义与手写笔记整理成「识别 → 定位 → 排他」的可执行系统。

## 内容

- **十章 / 100 个百大图形**：每章含识别信号、综合导图（讲义原文）、先判断 N 件事、百大逐条考点、案例与答案、易错、决策流、口诀。
- **254 个编号案例 + 拓展演练**：按百大编号索引，附年份省份与答案。
- **飞哥传书三行**：共性识图 / 细节定位 / 选图思维。
- **七步解题流程**：审题 → 共性识图 → 定规律池 → 细节定位 → 验证 → 选项排他 → 复核。
- **训练复盘**：三轮训练、错题本、错因六类、复盘五问。

## 安装

**方式一（推荐）**：下载 `dist/龙飞百大图推.skill`，在 Qoder 的 Skill 上传入口直接安装。

**方式二**：把仓库根目录复制到 Qoder 的用户 skills 目录，并命名为 `longfei-tuxing-tuili`：

```bash
# Windows (Git Bash)
cp -r . "$HOME/.qoder/skills/longfei-tuxing-tuili/"
```

或直接放在项目的 `.qoder/skills/longfei-tuxing-tuili/` 下。确保 `SKILL.md` 位于目录根部。

## 使用

在 Qoder 中说「用龙飞图推做这道图形推理题」或直接贴题；skill 会按 `SKILL.md` 的路由进入对应章节。

- 做题：`references/02-解题总流程-七步.md`
- 查答案：`references/13-百大图形索引表.md`
- 考前速查：`references/00-考场速查.md`
- 复盘：`references/18-训练复盘.md`

## 来源与边界

- 来源：龙飞百大图形推理课程 11 讲（L01-L11）、配套讲义 12 册（H01-H12）、手写笔记（红/蓝批注）。
- 只覆盖**图形推理**，不含定义判断、类比推理、逻辑判断。
- 答案以讲义红勾为准；无勾选时取「正确答案：X」；两者都无则标「原书未给答案」。
- 已知冲突与存疑见 `references/17-PPT讲义来源对照.md`。
