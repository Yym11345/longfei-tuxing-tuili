# 龙飞百大图推 · Skill 包

行测图形推理的解题系统，基于龙飞「百大图形」课程体系（11 讲 PPT + 12 册讲义 + 手写笔记）整理。

## 这个包解决什么

图形推理题难在两件事：**看不出是什么型**、**看不出规律在哪**。本包给出可执行的两段式答案：

- **飞哥传书三行**：共性识图 → 细节定位 → 选图思维
- **七步解题流程**：审题 → 识图 → 定池 → 定位 → 验证 → 排他 → 复核

配套十章分类、100 个百大图形样式、每类固定规律池，以及 254 个编号案例与拓展演练。

## 包结构

```
longfei-baidai-tuitui/
├── SKILL.md                    # 技能定义与执行入口
└── references/
    ├── 01-…18-*.md             # 十八份参考文档（分类表、规则库、例题库、复盘等）
```

## 使用方式

在 WorkBuddy 对话中直接说：

```
这道图形推理题属于哪一类？帮我定位规律
用龙飞百大图推的七步法走一遍这道题
四个选项怎么排除？教我命题人的出题思路
```

技能会按 SKILL.md 的七步流程逐步讲解，而不是直接报答案。

## 打包

```bash
python build_release.py src/longfei-baidai-tuitui dist
```

产出 `dist/longfei-baidai-tuitui.zip`，可用于 WorkBuddy 开放平台上传。
